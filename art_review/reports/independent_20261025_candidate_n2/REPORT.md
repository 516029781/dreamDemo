## 3. 视觉判断与返修要求

### N01 / ENV geometry（最高优先级，major）

`N01_tree_hedge_before_after.png` 可见修后树冠更密，绿篱不再只有裸露团块；但正式镜头仍有明显重复的角面叶簇、偏粗直的分枝、树冠边缘的漂浮叶片，远景绿篱像连续低多边形带。花坛外缘有硬三角面，长椅/栏杆缺少 P1 的真实厚度和细腻倒角。P1 `t015s` 的前中后景结构和材质细节更多，当前大面积空铺地仍主导画面。**先改可见的主树、花坛、长椅和背景植被母版**，保留现有道路与角色坐标；在相同机位交同尺寸全景和三处近景。验收要看不到显眼重复角面/悬浮叶卡，核心 `geometry_craft` 至少 3/4。

### N02 / material + light（major）

树影已从整块硬影改为叶卡斑驳，方向一致，改动有效；但地面铺砖偏均匀、接缝与磨损缺少尺度变化，木/金属远看趋于平色，土面大块深褐与浅铺地对比生硬。画面整体仍偏平、冷暖反弹和接触层次弱于 P1。**先在同一材质母版上处理石/木/金属的粗糙度、边缘与污渍分布，再调环境填充与接触阴影**；同时检查 8192 阴影设置在微信目标设备上的成本，不能用桌面截图推断真机可承受。

### N03 / UI paper + doodle（major）

N03 确实增加了浅透纸面、细纹和虚线装饰；但任务卡、右下操作、对白仍是规整矩形构件，手绘图标数量/笔触差异少。正式对白面板占画面下部近三分之一，纸面高亮使背景关系变弱；小字偏浅。P1 `t044s` 的对白更薄、边缘更轻，涂鸦形成局部节奏。**在同一 UI 母版上缩减对白高度和实色覆盖，改善字色对比，增加少量具有共同笔触的图标/边角不规则性**。先提交任务卡、对白和右下按钮三态同屏，检查普通、暂停、竖屏状态不回退。

### MIX coherence（随 N01–N03 修，不单独堆特效）

锁定角色的线稿和面部清楚，但背景几何/材质仍偏粗简，人物像高精度插画放在低模棋盘上；光照对人物与场景的作用差异明显。完成 N01–N03 后在**同一镜头、同一时刻**重做 ENV/CHAR/UI 叠加截图，再检查角色脚底接触、树前/树后、人物与环境明度关系和 UI 注意力分配。

### 新发现 N09 / 暂停恢复回跳（行为缺陷）

独立运行先移动角色，再进入 `__courtyard.setPause(true)`；暂停期间键盘/触控位移均为 0。调用现有恢复入口 `__courtyard.setPause(false)` 后，角色从已移动位置回到初始点：键盘路径约 **0.6 m**，触控路径约 **1.2 m**，且不需要新输入。源码中 `setPause(false)` 调 `resetView()`，后者 `playerPos.set(0, PAVING_TOP, -5.2)`。此前 Q04 在初始点暂停，故 `resumed_without_input_m=0` 未覆盖“移动后暂停”。需明确恢复与重新开始为两个不同动作：恢复保留玩家坐标/任务/相机目标，清输入状态；重新开始才归零。增加非初始坐标的键盘与触控回归，核恢复前后世界坐标和下一次新输入。竖屏返回横屏也调用 `resetView()`，应一并检查是否回跳。
