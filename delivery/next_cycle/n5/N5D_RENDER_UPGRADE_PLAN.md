### S3　顶点色 AO（落地感，先做——它影响 S1 的调色输入）

**改动文件**：`tools/blender_n5/courtyard_lib.py`（AO 计算）、`tools/blender_n5/build_map001.py` /
`build_env_courtyard.py`（调用）、`demo_n5/assets/scripts/CourtyardBootstrap.ts`（材质启用 vertexColor）

**做法（确定性、非光照烘焙，避免 Cycles 全场景烘的开销）**：

1. **高度渐变 AO**：每个网格顶点按世界高度 z 做暗度梯度——z=0 处 0.72，z≥0.8m 处 1.0，
   线性插值。树冠/高物体根部自然压暗。
2. **接触暗化**：对落在铺装/土壤上的物体（长椅脚、花箱底、树干根、桶底），
   在根部半径 0.15–0.30m 内的**地面**顶点额外压暗至 0.78（按距离衰减）。
3. 导出 GLB 时写入 `COLOR_0`；引擎端材质开启 `vertexColor` 乘算
   （builtin standard 支持，Bootstrap 建材质时逐个打开）。
4. 参数进 `N5_AO` 环境变量（强度/半径可调，回退无需改代码）。

**不做**：Cycles 全场景 AO 烘焙（CPU 代价不成比例）、贴图式 AO（我们走顶点色路线）。

**可证伪预期**（构建前写入 decisions.jsonl）：
- 接缝/根部区域亮度中位数比现在低 8–15%，且 hue 保持 ≤30°
- edge_pct 变化 ≤ ±1.5%（AO 不应改变细节密度）
- 目视：物体"钉"在地面上，无新暗斑伪影

**验收**：同机位前后图并排，根部/接缝有明确但不过度的接触阴影；
`N5_AO=0` 一键回退验证。

### S4　树叶卡片纹理（治"绿油油一坨"）

**改动文件**：新增 `tools/textures_n5/make_leaf_atlas.py`（纯 PIL 程序绘制），
`tools/blender_n5/build_env_courtyard.py` / `courtyard_lib.py`（卡片 UV + 材质），
`CourtyardBootstrap.ts`（alphaTest 材质）

**做法**：

1. 程序生成 512×512 叶片图集（**PIL 绘制，非 AI 生图**）：
   - 8–12 个手绘感叶簇形状（聚合圆斑、锯齿边），alpha 形状硬边
   - 每个形状内部自带明暗渐变（顶部亮 1.0 → 根部 0.55），色相用调色板中值
2. Blender 侧：卡片四边形不再用纯色材质，改为 UV 对齐图集单元 + alphaTest 材质；
   卡片顶点色继续承担"上下明暗"（与图集渐变叠乘）
3. 树芯内层簇（B3 刚加的 34 簇）改用图集中**最暗**的 2 个单元——树心读作"深处的叶子"
   而不是色块坨
4. 图集 PNG 入 `demo_n5/assets/resources/textures/`，哈希入 manifest

**可证伪预期**：
- 树冠区（游戏机位）fft_hi 由当前值下降 ≥0.04（卡片形状替代高频噪声）
- 树冠区饱和度标准差上升（有明暗层次），mean 变化 ≤ ±0.03
- 四机位无任何光滑椭球残留；三角面数不增（只换材质与 UV）

**失败处理**：若 alphaTest 在微信端出现排序毛边，降级为不透明卡片（保留渐变，去掉 alpha），
形状改由卡片四边形本身的锯齿轮廓承担。

### S1　后处理调色（治"灰蒙蒙"的最大杠杆）

**改动文件**：`demo_n5/assets/scripts/CourtyardBootstrap.ts`（或新增 `PostGrade.ts`）；
不引入第三方库。

**做法（WebGL1 兼容路线，微信可用）**：

1. 主相机渲染到 RenderTexture → 后处理相机全屏 quad 上采样输出
2. 后处理 shader（单 pass，全部参数可调常量）：
   - **暖分离色调**：阴影乘 (1.00, 0.86, 0.74)（压向暖褐），高光乘 (1.00, 0.96, 0.88)（提向奶油）
   - **S 曲线**：pivot 0.45，强度 0.12（对比不加曝）
   - **饱和**：全局 ×1.06，仅对 hue 0–35° 的像素额外 ×1.10（把艳留给暖色）
   - **暗角**：强度 0.12（聚视线中心，业界标准做法）
3. 提供 `POST_GRADE=0/1` 环境开关，交付图必须 A/B 各一张
4. 风险预检：微信端 RenderTexture 在 WebGL1 可用（业界小程序通用做法）；
   性能上 1280×720 单 pass 全屏代价可接受，真机验证留到微信测试阶段，不影响本轮

**可证伪预期**（相对 S3/S4 之后的画面）：
- p95：0.776 → ≥0.82（高光提奶油）
- 阴影像素 hue：45° → ≤30°（压暖褐）
- Hasler-Süsstrunk colorfulness：+15% 以上
- 色相 0–30° 占比：≥0.55
- **反向保护**：p5 不得低于 0.16（暗部不能糊死）；若 p95 达标但画面发"脏"，先降阴影色调浓度再降暗角

**验收**：A/B 并排图 + probe 数值 + 与 P1 参考三方对比，目视"更艳但不是更红"。

### S2　三色阶着色（决策点，默认缓一缓）

**前提**：S1+S3 完成并出对比图后再决定。理由：S2 改动面最大（逐材质换 effect），
而 S1 的 S 曲线已经能制造"分档感"的第一印象；先看便宜的够不够。

**若上，缩小版做法**：只对**地面铺装、墙体、大件道具**（长椅/花箱/井栏）换
Cocos builtin toon effect（[官方文档](https://docs.cocos.com/creator/3.8/manual/zh/shader/effect-builtin-toon.html)），
3 色阶 + 暖 ramp；树叶卡片和角色**不上 toon**（卡片本身已是分块明暗，角色源锁定不动）。

**可证伪预期**：大色块内部出现 2 条稳定明暗界线（不是渐变）；edge_pct 增幅 ≤ +1.0%。
**失败处理**：toon 与贴花阴影冲突时，只保留墙体 toon，或整体放弃 S2（有独立回退，不影响其他批）。
