### B2　植被合法性（对应主诉 2 与 R1/R2）

**改动文件**：`tools/blender_n5/build_map001.py`，新增 `tools/n5_check_vegetation.py`

**根因**：第 801 行花坛草只判了**花坛中心**，随后逐株散点无判定；`on_paving()` 依赖模块中心列表而非实际铺装覆盖。

**改动**

1. `on_paving(x,z)` 改为"点落在任一铺装矩形内（由 `PAVING_CENTERS` ± `PAVING_HALF`，含 inset）"
2. `_add_turf_patch()` 增加 `blocked` 回调参数，**逐株**判定，被挡的株跳过并计数
3. 所有 `_add_turf_patch` 调用点传入 `blocked=on_paving`（花坛/花箱内的除外，由容器判定）
4. 构建时输出 `art/candidates/candidate_n5/vegetation_audit.json`：
   每株 `(x, z, on_paving, container_id)` 与汇总计数
5. 新增检查脚本 `tools/n5_check_vegetation.py`：输出 `violations`（根点在铺装上的株数）与
   `orphans`（无容器归属的株数）

**验收**

- n5c：`violations == 0` 且 `orphans == 0`
- **n5b 作为失败样本必须先跑出 >0**（证明检查有效），两个审计文件都入包

### B4　铺装 / 土壤 / 构图（P4/P5/P9 + R3/R5）
