## 一、一句话结论

P1 是**暖色单色调 + 高对比 + 深暖阴影 + 亮暖高光**的写实卡通风：
98% 的彩色像素是暖色，主色相集中在**红橙 12–32°**，暗部压到接近黑色的**暖红棕**，
亮部推到奶油/杏色，中间调偏暗。它**不是**"明亮鲜艳"，而是**"暗、暖、有亮点"**。

我们目前是**中亮度、中对比、黄橙 30–60° 大面积中饱和**——这正是"灰蒙蒙、土、不吸引人"的来源。

## 二、量化配方（P1 实测 vs 我们）

| 指标 | P1 五帧均值 | n5b 实测 | 差距 | 目标 |

| 色相 30–60°（黄橙）占比 | 0.181 | **0.889** | 过度集中 | ≤ 0.35 |

| 亮度 std（对比） | 0.208 | 0.179 | 我们偏平 | ≥ 0.20 |
| 亮度 p5（暗部深度） | 0.201 | 0.239 | 我们暗不下去 | ≤ 0.21 |
| 亮度 p95（高光上限） | 0.818 | 0.776 | 我们没有亮点 | ≥ 0.82 |
| 饱和 mean | 0.300 | 0.370 | 我们偏土 | 0.28–0.33 |
| 饱和 p90（局部艳丽度） | 0.539 | 0.619 | 我们大面积过饱和 | 0.50–0.56 |
| 冷色占比 | 0.017 | 0.001 | 都极低 | ≤ 0.05 |
| 阴影色 | 见下 | `#38311C` | 我们阴影偏橄榄 | 见下 |
| 高光色 | 见下 | `#CCBFA7` | 我们高光偏灰 | 见下 |

**关键判读**：P1 的饱和"均值低、峰值高"——大面积是低饱和暖灰（石、墙、土），
小面积是高饱和橙红（叶、招牌、布幡）。我们现在相反：**大面积黄橙中饱和**，
所以既土又平。要模仿的不是"更艳"，而是**把艳度集中到少数区域**。

### 4.3 饱和度分配（最重要的一条）

不要整体加饱和。按面积分配：

| 区域 | 目标饱和 | 做法 |
|---|---|---|
| 铺装、墙体、土壤（大面积） | **0.15–0.25**（低） | 降低现有石/土色饱和，靠明度变化出层次 |
| 树冠叶团（中面积） | **0.35–0.50** | 橙红为主，明暗拉开 |
| 点缀（花草、招牌、布幡、角色） | **0.55–0.70** | 唯一允许高饱和的区域 |

这样均值会落到 0.30 左右，而 p90 保持 0.54 —— 与 P1 一致。

## 五、素材摆放的现实逻辑（用户第 2 条）

参考图里的摆放有很强的现实规则，我们要照抄这些规则，而不是照抄物件。

### R1　有机物不能长在硬质铺装中央

- P1 观察：石板上只有**污渍、裂缝、落叶、接缝处零星草叶**，没有成丛草。
- 我们现状：花坛外一整丛草长在砖面中央（`_zoom_paving_grass.png`）。
- 规则：**草根落在铺装砖面上的株数 = 0**；接缝草叶覆盖面积 ≤ 砖面 2%。
- 检查：`tools/n5_check_vegetation.py`，当前版本必须报 >0 作失败样本。

### R2　植被必须有容器承载

- P1 观察：草全部在**花坛、花箱、墙头、种植槽**里，溢出的只沿容器边缘向下垂，不落地铺开。
- 规则：每株草的基点必须位于某个容器多边形内；允许沿边缘外溢 ≤ 15 cm。
- 检查：同上脚本，输出"无容器归属的草株数"，必须为 0。

### R3　道具按功能成组，不孤立散放

- P1 观察：长椅+路灯+桌子成组；车辆+货箱+警示锥成组；布幡沿动线连续。
- 规则：每件道具须属于一个"功能组"（≥2 件、间距 ≤ 3 m），组沿可行走动线布置。
- 我们现状：长椅、路灯、花坛各自孤立。
- 检查：布局图（`MAP001_topdown.png`）上标注功能组，孤立道具数 ≤ 1。

### R4　实体必须有接触阴影，方向一致

- P1 观察：每个物体有明确落地阴影，方向统一。
- 规则：树、长椅、路灯、花坛、角色、NPC 均有接触影；所有阴影方向与 key 方位角偏差 ≤ 15°。
- 检查：Q03 遮挡探针 + 阴影视图。

### R5　铺装磨损沿"使用逻辑"分布

- P1 观察：裂缝沿人流动线延伸，水渍在排水口/花坛边，边缘磨圆。
- 规则：深色/破损砖块**成组**（≥2 块相邻）出现在动线与容器边缘，不在几何中心随机单块出现。
- 检查：深色砖成组率 ≥ 90%。

### R6　附着物不跨材质边界

- P1 观察：爬藤沿墙面延伸，到墙顶/地面边界即止。
- 规则：爬藤、海报、涂鸦不得跨越材质边界（墙→地、石→土）。
- 检查：目视 + 边界处截图抽检。

## 六、验收标准（n5c 用）

| 项 | 目标 |
|---|---|
| 色相 0–30° 占比 | ≥ 0.55（现 0.067） |
| 色相 30–60° 占比 | ≤ 0.35（现 0.889） |
| 亮度 p5 / p95 | ≤ 0.21 / ≥ 0.82 |
| 亮度 std | ≥ 0.20 |
| 饱和 mean / p90 | 0.28–0.33 / 0.50–0.56 |
| 阴影色相 | 13–22°（现 45°） |
| 草根落砖面株数 | 0 |
| 无容器草株数 | 0 |
| 深色砖成组率 | ≥ 90% |
| 孤立道具数 | ≤ 1 |

全部指标用 `tools/p1_style_probe.py` 与 `tools/n5_check_vegetation.py` 复跑，
并把 n5b 作为**失败样本**一并记录（色相 0.067、草株 >0），证明检查有效。

## 七、已知局限

- 参考帧含景深虚化与运动模糊，会拉低其 p95、抬高其低明度占比；直接对齐数值不等于视觉一致，**最终以肉眼并排判断为准**。
- 五帧是不同场景，色板是风格统计，不能当作某一具体场景的取色表。
- 饱和度分配建议基于面积假设，实际需在 n5c 出图后按实测回调一次。
