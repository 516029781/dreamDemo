## 5. 交付尺寸 L0-b 三候选复测（1680×2478 / 24 spp / seed 0 / 同相机）

| 指标 | A 现状 | C AgX+MHC | D Standard −0.15 | 目标 |
|---|---:|---:|---:|---|
| A1 陆地 L p50 | 0.766 | 0.711 | **0.683** | 0.58–0.64 |
| A2 L>0.80 | 42.3% | **2.2%** | 3.4% | ≤22% |
| A3 L<0.30 | 3.4% | 5.0% | **5.3%** | 10–15% |
| A4 跨度 p90−p10 | 0.444 | 0.362 | **0.399** | ≥0.55 |
| A5 裁切 L>0.97 | 2.01% | **0.00%** | 0.79% | ≤0.8% |
| A13 平均饱和 | 0.208 | **0.156** | **0.210** | ≥0.24 |
| S1 light_land | 0.614 | 0.664 | 0.497 | ≥0.45 |

**三条结论**

1. **两个候选都解决亮端堆积与高光裁切，但都不解决暗部真空**（3.4%→5.0/5.3%，目标 10–15%）。
   暗部只能靠 P3 的 L1 阴影 + L2 明度分工。
2. **A4 明度跨度不升反降**（0.444 → 0.362 / 0.399）——亮端压下来了、暗部没起来，
   动态范围反而变窄。这是 v1.0/v1.1 都没预料到的，说明**单靠色调映射不可能达成 A4**，
   P3 才是决定成败的一轮。
3. **A13 两个候选都未达标**（C 洗到 0.156、D 0.210 < 0.24）。
   → **L0-a compositor 的补饱和不是可选优化，是必需项**。

### 目视（`renders/_cm_candidates.png`）

A 最亮、最像"纸片"；C 明显发灰发白，暖调与绿植几乎被洗掉，厂房细节变糊；
D 保留暖调、亮端收敛、四厅与试车间细节仍清楚，整体最接近 P1 想要的完成度。

### 推荐：**D（Standard / None / exposure −0.15）**

- 保住饱和度（0.210，不倒退），A4 掉得最少（0.399），A1 更接近目标（0.683）；
- 只改一个标量，**不动 `view_transform`** → 与 P1（同为 Standard）语义一致，
  既有色彩统计口径变化最小，证据链最干净；
- C 要额外补饱和 + 补跨度 + 重跑 S2/S3/S15，代价明显更大。

⚠️ **这是 P0 阶段的倾向，不是最终锁定**：compositor（L0-a）会改变饱和度与明度，
D 的参数应在 compositor 落地后按同条件复测再锁。

### 分期微调建议

方案 §6 原为 P1=L0-a compositor → P2=L0-b 色调映射。建议**对调**：

- **新 P1**：先落 D（一个标量、最小改动），锁定新基线并出同机位前后对照；
- **新 P2**：在稳定基线上逐个 A/B compositor 模块（一轮一个主假设），
  顺便把 A13 补到 ≥0.24；
- P3（L1–L2）仍是决定暗部与跨度的关键轮。
