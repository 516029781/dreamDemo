## 这份数据是什么

- **PhysX 碰撞几何**：按物理精度生成的简化面，不是渲染模型

- 59 块 127×127 高度瓦片；瓦片不含位置，作者靠离线相关性反推摆放，航天基地相关性仅 **0.25**（本图**未叠加地形**，只渲染建筑碰撞面）

## 生成图

| 文件 | 内容 | SHA-256 前 16 位 |
|---|---|---|
| `plan_overview.png` | 整体俯视结构图 + 100 m 坐标网格（密度定亮度、高程定色相） | `910db3b31a6e8f74` |
| `plan_core_zoom.png` | 核心建筑群局部 2× | `3176d3a2ff428a75` |

生成方式：每个三角面取 7 个采样点投影到水平面，逐像素取最高高程并累计命中次数；
密度做亮度、高程做色相，得到"平面图 + 高差"的混合读法。
碰撞体多为薄壁、常缺屋顶，所以图面接近**建筑平面图**而非实体模型渲染。

## 读图约定

- 亮 = 碰撞面密集（墙、设备、构件）
- 暖白 = 高处（塔架、高台），靛蓝 = 低处（地面、下沉区）
- 四周散落的圆形团块是**植被/岩石碰撞体**，不是建筑
- 网格间距 100 m，比例尺 200 m，方位为上北
