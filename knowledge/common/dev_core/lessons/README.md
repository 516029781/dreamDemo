# 通用开发经验（跨业务）

本目录只收**跨业务验证过**的经验；单业务经验留在对应业务包。

## 收录门槛

| maturity | 条件 |
|---|---|
| `proposed` | 有明确假设与验证方法，尚未复测 |
| `observed` | 在至少一个候选/任务中被观察到，有证据 SHA |
| `reproduced` | 在同一业务内独立复测有效，记录反例 |
| `reusable` | 至少两个不同业务包复测有效，记录边界与反例 |

- 未经验证的单次试验不得写成“最佳实践”或成功案例。
- 每条须记来源候选、源/图 SHA、适用条件、失败边界、复测次数、责任业务包。
