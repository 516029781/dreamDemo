# 当前制作配方：P1 秋日风格静态地图

更新：2026-10-29。适用范围：固定镜头的单张环境静帧。状态：当前执行配方；唯一整图视觉参考是秋日 `t084s.jpg`。本配方是流程说明，不是“成功成图”案例。

## 一次连续任务的四个关口

1. 锁目标。校验 `reference/_raw_screenshots/P1/t084s.jpg` SHA；按 P1 秋日标准分析画面和未来可行走环境边界。将 CW-8/CW-9 JSON 仅用于数据解析/Harness 结构规则，不用于视觉目标。
2. 定空间。只搭地图区域、可行走地面、高差、主设施和有效参考中确实存在的地形/植被灰模；调相机、检查遮挡和世界坐标支撑；保存一张灰模图和一张初步色块图。
3. 组合试画。用同一相机把地面/地形、代表性设施、材质、参考中存在的植被和目标光色一起渲染；按新标准逐项检查。任一项未过就改源重渲，不扩细节。相同方法两轮没有可见改善时换方法。
4. 完整画面与封包。每轮先自评并人工核对机械资料（自动 preflight 尚未实现），明显低于目标就先修，不反复启动盲评。制作侧认为候选达到目标且资料齐备后，再让两个分开的盲评过程针对同一最终渲染评分；任一失败并返修后，新渲染必须重新取得两份评审。重开 Blender 场景复现最终图，按当前工作单写 REVIEW.md、DELIVERY.json 和 GATE_REPORT.json。项目 Stop hook 只有在鼠鼠项目受信任且本会话明确启动地图制作时才自动检查；否则由执行模型手动运行项目质量 gate。

## 一批返修只记六件事

- 主要假设和预期的可见变化。
- 实际改动的源文件/参数。
- 固定相机下的修改前后图。
- 命令、退出码、耗时和输出 SHA。
- 目标区域以及未修改区域的反例观察。
- improved、unchanged 或 worse，以及下一步决定。

## 结束判定

低于 85、任一维低于 3 或硬门槛失败时，状态为 `rework_required`，必须实际修 Blender 原生源、同机位重渲并复评；正常完成只允许 `target_met`。只有真实外部阻塞并保留证据时才可结束为未完成，不能用 `quality_below_target` 作为正常收尾。哈希、地图数据与接地检查通过只证明相应机械条件，不等于美术通过。
