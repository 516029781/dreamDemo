## 1. 阶段与用例分布

| 阶段 | 用例重点 | 通过证据 |
|---|---|---|
| 需求冻结 | 参考存在与 SHA、范围/禁止项齐全、blocking 已解决、无孤儿需求 | 清单、问题单、追踪矩阵 |
| 方案预览（N4 前） | 布局/锚点/结构；新风格须粗色光+代表小样 | 预览板、rubric、SHA |
| 首批原型 | 体块/遮挡/接地（按类型扩展路线/状态/比例） | 同条件原型图与关系清单 |
| 风格小样 | 轮廓/材质/细节/组合风险 | style sheet、逐项 rubric、SHA |
| 完整产物 | 全量视觉评分、硬门槛、源图绑定、重开复现 | 对照图、评分证据、SHA、复现记录 |

## 2. 用例清单

见 `test_cases.json`；每条须含 TEST-ID、覆盖 REQ-ID、阶段、检查类型、通过标准、证据路径、失败返修规则。

## 3. 数值指标的使用边界

- 只有具备同类样本、遮罩与容差依据的指标才可作为门槛。
- 未校准的全图统计（HSV/亮度/边缘）一律 `diagnostic_only`，不得记作 PASS。
- 机械用例只证明文件/尺寸/哈希/参数；对象关系与重开结果须有实际解析器或执行命令，否则标为人工检查。

## 4. 失败与重跑

- 失败记录：`TEST-ID → 现象 → 区域/对象 → 根因假设 → 源级修改 → 预期变化 → 重跑用例`。
- 图 SHA 变化后，旧视觉通过证据失效；重跑受影响用例，交付前跑全量。
