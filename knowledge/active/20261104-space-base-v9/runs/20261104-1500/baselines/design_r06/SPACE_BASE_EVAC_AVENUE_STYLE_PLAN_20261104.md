## 2. 为什么现在像"小路"

1. **路缘无界面**：18 m 宽的路，两侧 0 内容 → 视觉宽度只剩"色带"，读成小径。
2. **无标线无接缝**：整块纯色铺装，没有车道线/边线/分缝节奏 → 缺尺度参照。
3. **无桥感**：跨水段没有栏杆、桥墩、灯柱，看不到"这是一座桥"。

### 5.7 近景出图管线（v09 实装，2026-11-04）

近景不是"渲一张图"，是**两遍渲染 + 一遍 2D**，因为赛璐璐与描边在 3D 里做不干净：

| 步骤 | 做法 | 为什么 |
| --- | --- | --- |
| ① Beauty | Cycles 40 spp + 降噪，1920×1080，35/50 mm，f/4–5.6 | 需要真实 GI 与阴影 |
| ② Depth | 材质覆盖 + `LightPath.RayLength` 发射着色，**1 spp** 出归一化深度（1 近 / 0 远，220 m） | 深度只有 5 秒成本；用它做描边与空气透视，不会把贴图噪点当边界 |
| ③ NPR | 空气透视 → 5 段色阶（**只压 V，保 H/S**）→ 深度+亮度双通道描边 → 冷影暖高光调色 → 纸纹暗角 | 色阶若直接量化 RGB 会色相漂移（v06 已踩坑） |

配套三条硬规则：
1. **描边只认深度不连续**（阈值 0.012），亮度边缘只作辅助（阈值 0.085、权重 0.8），否则地面颗粒会被描成噪点；
2. **色阶强度 0.72、5 档**——档数再少会丢建筑立面层次，再多就不像插画；
3. **空气透视强度 0.34 / 衰减 120 m**——超过 0.5 会把半岛那端糊成灰雾（第一版试过，已回退）。

> Blender 5 的合成器改为节点组（`scene.compositing_node_group`），旧的
> `CompositorNodeComposite` 与 File Output 的 PNG 槽都已移除 —— 深度改走材质覆盖是更稳的路子。
