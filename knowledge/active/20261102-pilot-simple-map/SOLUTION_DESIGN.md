## 3. 光照

- 单一主光：Sun，方向自左后上（方位 (−6, 8, 12) 指向原点），能量 3.2，角径 0.04 rad。
- 环境：World 冷灰蓝 (0.52,0.56,0.60)，强度 0.45，只作补光，不产生第二方向硬影。
- 预期：所有投影朝画面右前下方，方向一致（TEST-03 判定依据）。
- 已知坑：sun 为 QUATERNION 旋转模式，必须 `rotation_quaternion = dir.to_track_quat('-Z','Y')`；
  赋 `rotation_euler` 无效。此写法取自 `r1_light.py`。

## 4. 材质

| 族 | 基色（sRGB） | 粗糙度 | 备注 |
|---|---|---|---|
| 石（台/踏步/墙） | #B9AD9A / #C6BBAA | 0.82 | 噪声 6 尺度做明度扰动，防塑料感 |
| 木（箱） | #8A5A34 | 0.75 | 波纹纹理极弱，仅破坏均匀 |
| 金属（桶/灯柱） | #4E5257 | 0.35，metallic 0.85 | 单一高光，不做锈 |
| 地 | #7D7264 | 0.95 | 大尺度噪声，避免平铺感 |

全部 sRGB 值经 hex→linear 转换后写入 Principled Base Color；画面不得出现纯黑/纯白（TEST-04）。

## 5. 渲染参数

| 项 | 取值 |
|---|---|
| 引擎 | Cycles，CPU，seed 0，animated_seed off |
| 采样 | 预览 16 spp / 终图 64 spp，OIDN 降噪 |
| 色彩管理 | AgX，look None，exposure +0.30 |
| 输出 | PNG 8-bit sRGB，960×540 |
| 预期耗时 | 预览 < 20 s，终图 < 90 s |

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 重渲非逐位一致 | TEST-05 误判 | 事前声明 RMS ≤ 2/255 容差，不比 bit |
| 石台与台阶接缝露缝 | TEST-02 失败 | 踏步与台面各留 1 cm 重叠 |
| 后墙挡光导致台面死黑 | TEST-04 失败 | 后墙高 2.0 且偏暗，主光来自左后上不被完全遮挡 |
| 灯柱过细产生锯齿 | 目视噪声 | 半径 0.06 + 64 spp + 降噪 |
