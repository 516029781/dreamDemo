- 世界 240×420、像素映射 `px=x*7 / py=(166−y)*5.7344`、北朝上；
- 四室 54×54（v08）、五区配色 S15 目标值、总裁盒开顶、水面出画；
- 撤离点 (221,−214)、G5 集装箱遮挡位、G4 黄框/蓝光探针；
- 主交付仍是 master / core / hero / jpg 四件套 + checks；近景 P1–P8 不进游戏包；
- v09 只读留档，v10 独立 candidate、独立 run、独立 builder。

## 3. 不做

- 不做喷泉 / 流水 / 瀑布；不做下沉花园（保持单层，用池 −0.05、花坛 +0.35、压顶 +0.12 做层次）；
- 不改四室内部、不改撤离点、不改 G5 集装箱位、不改 S15 五区；
- 不做角色绑定 / 动画；不做 AI 直出整图；不随包商业字体。
