# 静态地图制作流程：通用问题与提效优先级

日期：2026-11-01。范围：当前 P1 静态环境图流程，提炼为以后其他地图也能复用的规则。本文件是流程审计与改进建议，不改动现行评分门槛、场景或候选证据。证据来自 V25 的 `REVIEW.md`、`DELIVERY.json`、`GATE_REPORT.json`、`renders/` 实物，以及当前 `START_HERE.md`、`STATIC_MAP_WORKFLOW_20261028.md`、`BACKGROUND_PLANS_INDEX.md`。

## 建议先做的三项改造

1. **先修候选绑定与入口**（P0-1/P0-2）。这是准确性的地基。当前 V27 图仍放在 `v25/`，旧 `DELIVERY/GATE` 指向删除文件，不能拿它宣称达到任何最终门槛。每次候选晋级都新建身份，并原子更新入口与绑定。
2. **再修图像诊断口径与根因定位**（P0-3/P1-1）。参考截图有 UI/人物，先确定可比较区域；任何异常先确定是几何、材质、光照还是合成器，减少无目标重渲。
3. **最后把方法小样和渲染分级写入工作流**（P1-2/P1-5）。先用一棵树、一片草池、一组设施验证做法，再扩批；记录每种分辨率/采样的次数和机时，下一轮才可给可信的提效比例。

## 量化方式与实施顺序

先补一次真实基线：每批记录开始/结束时间、诊断试图次数、正式渲染次数与分钟、盲评次数、批量回滚对象数、晚发现几何错误数、证据失配数。计算：

- **时间改进** = `(基线总工时 − 新流程总工时) / 基线总工时`。渲染机时与人工判读时间分开；不拿正式图297.7秒推算整轮工时。
- **准确性改进** = 比较候选绑定错误、错误根因导致的返工批数、晚发现缺陷、盲评分歧与最终质量分数。高分与低返工须同时成立。
- **停止规则**：同一假设两次无改善就换定位层级或资产方法；继续制作直到现行85/逐维3及硬门槛，或真实外部阻塞。不能把“方法失败两次”写成任务自然结束。

建议实施顺序：第1批做绑定/入口自动检查；第2批校准可观察区与诊断流程；第3批上小样门与分级渲染；第4批根据实测时间决定清理脚本及知识库精简。每批只改一个流程假设，保留改造前后的错误率和工时，避免同时改规则后无法归因。
