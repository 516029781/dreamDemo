# P0 锚点：23 个维度的 3 分与 4 分分界

本文件由 `build_p0.py` 生成，是 P0 的唯一评分依据。
打分时只看锚点里指定的帧与区域，不引用其他截图，不参考历史自评分。

档位定义（验收文件 §3）：3 = 正式机位达到该特征且无关键问题；4 = 在规定多机位与多状态下均精致稳定。
因此 4 分的判据一律包含“换机位仍成立”，单帧做到不算。

## 两条通用规则

**R1 机位不可用则不得给 4。** 若锚点指定的机位里目标被遮挡超过一半或出画，该机位不计入；剩余可用机位不足两个时，该维最高 3 分。
**R2 尺寸类判断以 1:1 裁图为据。** 判断“缩到 xx px 是否可辨”，看 `evidence/` 下的 1:1 裁图，不要在原图上凭印象判断；放大图只用于确认形状，不用于判断可辨性。
**R3 角色是面向相机的 2D 合成体。** 角色由 `PlayerWorldQuad` 承载，每帧执行 `setRotation(mainCamera.rotation)`，M1/M2/M3 三个机位看到的是同一张贴图，差异只在屏幕尺寸、遮挡和背景对比。因此 CHAR 的 4 分档检验的是“三个机位都完整、清晰、不被遮”，**不是 3D 多面一致**；不得以“看不到侧面或背面”为由扣分。

## ENV

### composition_scale　权重 20　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）全图；F3（对白中景 · 1280×720）全图；F4（树后低角 · 1280×720）全图
- 3 分：三个机位都能读出前中后，角色躯干占屏高 17.1%（123 px）比例本身不小，但俯视机位铺地占下半屏 49.9% 且同明度，视线被拉平、没有明确落点；任一机位主体不被裁切。
- 4 分：至少两个机位能把视线收束到角色或主树，铺地退为背景；或在铺地上用明度梯度、铺法分区建立落点；换机位后收束关系仍成立。
- 实测：角色躯干 123 px / 17.1%（v4 修正，旧值 90.9 px 作废）；下半屏铺地色 49.9%

### geometry_craft　权重 20　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）中景 y=200–450；F5（告示板近景 · 满 · 1280×720）全图
- 3 分：可读物件只有树、环坛、长椅、路灯四类，彼此独立摆放；环坛是正圆、长椅是直板，没有连接件与倒角。
- 4 分：物件成组构成角落（花坛＋长椅＋灯），近景物件有厚度、倒角、连接件；缩到 1280×720 仍能看出构造而非剪影。
- 实测：F1 中景可读物件 4 类

### material_separation　权重 20　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）铺地 y=380–720；F5（告示板近景 · 满 · 1280×720）砖面近景
- 3 分：石与木能区分，但砖缝等宽、磨损是均匀噪点，铺地只有一种铺法；换机位后材质差异减弱。
- 4 分：主路、广场、边缘三种铺法可辨；砖缝不等宽，有苔、磨边与局部破损；石、木、金属三种粗糙度在同屏可区分，且不依赖换色。
- 实测：砖网格 17×9，缝宽恒定

### lighting_contact　权重 20　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）树冠下 y=300–380；长椅脚 y=560–590；F4（树后低角 · 1280×720）树干与地面
- 3 分：有明确主光方向，但叶片基本不投影，树冠只靠一张贴花；长椅与花坛脚下是柔光斑，没有接触阴影。
- 4 分：树冠在铺地投出边界可辨的长投影，长椅、花坛、路灯各有接触阴影；转灰度后仍保留不少于 9 档有效明度，暗部不死黑。
- 实测：灰度有效档 11 档；平均明度 126.2

### vegetation_depth　权重 10

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）树冠 y=40–300；F4（树后低角 · 1280×720）绿篱带
- 3 分：树冠下部光秃成枝裙，绿篱读作单层团块，冠内没有空隙。
- 4 分：冠内有空隙与明暗交替，绿篱分出前中后三层，且换机位后层次不塌。

### play_readability　权重 10

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）角色周围 x=300–700；F2（同机位 · 有 UI · 1280×720）角色与 UI 关系
- 3 分：角色可辨，但周围铺地明度接近，NPC 与主角明度差小；UI 出现后角色注意力被分走。
- 4 分：角色是画面第一落点，角色所在区域对比度最高；路径净宽可读；UI 出现时仍不压角色主体。
- 实测：最亮 10% 像素重心在屏高 34.9%，即背景带而非角色

## CHAR

### silhouette_proportion　权重 20　核心维

- 看哪里：M1（独立机位1 正面全景 · 无 UI）角色全身；M2（独立机位2 侧向45° · 无 UI）角色全身；M3（独立机位3 东南中位 · 无 UI）角色全身
- 3 分：角色外轮廓在 M1 可读，但 M3（188 px）下武器与裙摆粘连，脚部没有独立剪影，底缘是贯穿全身的平直硬切。
- 4 分：三个独立机位下外轮廓都干净，武器、发饰、裙摆、靴子各自分离；底缘有脚形而不是硬切，缩到 90 px 仍能分辨附件。

### line_quality　权重 15　核心维

- 看哪里：M1（独立机位1 正面全景 · 无 UI）角色外轮廓；M2（独立机位2 侧向45° · 无 UI）角色外轮廓；M3（独立机位3 东南中位 · 无 UI）角色全身
- 3 分：外轮廓清楚，内线密度不均；M3 放大后局部断线，衣褶有几处重复同一笔。
- 4 分：三个机位下外轮廓与内线同一笔触，不断线，放大不露重复；缩到 90 px 仍闭合。

### cel_color_light　权重 15　核心维

- 看哪里：M1（独立机位1 正面全景 · 无 UI）角色色块；M2（独立机位2 侧向45° · 无 UI）角色色块；M3（独立机位3 东南中位 · 无 UI）角色色块
- 3 分：色块正确，暗部是单纯压暗，没有环境色；三个机位明暗关系一致但没有随光向变化。
- 4 分：黑、白、灰三段清楚，暗部带冷环境色并与场景主光同向；M3 侧向机位下仍能读出体积。

### identity_consistency　权重 25　核心维

- 看哪里：M1（独立机位1 正面全景 · 无 UI）角色全身；M2（独立机位2 侧向45° · 无 UI）角色全身；M3（独立机位3 东南中位 · 无 UI）角色全身
- 3 分：可辨认，但三个独立机位里至少一个不完整或细节含糊，需要靠单帧印象补齐。
- 4 分：与锁定源同配件、同配色、同比例；M1/M2/M3 三个独立机位都完整可辨，不因场景重绘。按 R3，不要求看到侧面或背面。

### motion_contact　权重 15　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）角色脚下；M3（独立机位3 东南中位 · 无 UI）角色脚下
- 3 分：脚底与地面之间没有接触阴影，移动帧存在轻微滑动；M3 侧向机位下角色像是浮在铺地上。
- 4 分：多帧下脚底贴合地面，接地阴影随动作移动，停下时不留残影；三个机位都能读出脚与地面的接触。
- 实测：M3 角色脚下无可见接触阴影

### small_scale_clarity　权重 10

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）角色 x=380–500, y=470–630
- 3 分：看 `evidence/CHAR_screen_1to1.png`：90 px 时能读出人形、配色与武器大致位置，但眼睛与靴子轮廓分不开。
- 4 分：看 `evidence/CHAR_screen_1to1.png`：能指出眼睛位置，武器与靴子轮廓各自分离，轮廓内至少 3 个独立色块。
- 实测：角色高 123 px（v4 修正），1:1 裁图按 90 px 重采样

## UI

### layout_air　权重 15　核心维

### state_feedback　权重 15　核心维

- 4 分：默认、悬停、按下、暂停、对白、竖屏六态一致，状态切换有明确视觉回应。

### palette_restraint　权重 10

- 4 分：乳白与炭灰为主，只保留一种交互强调色，换状态不新增色相。

## MIX

### visual_language　权重 25　核心维

- 看哪里：F3（对白中景 · 1280×720）角色与场景同屏；F4（树后低角 · 1280×720）角色与树同屏
- 3 分：立绘的线条与细节密度明显高于场景，读起来像高精度贴片放在低模上。
- 4 分：角色与场景共用同一套描边、明度分档与纹理密度，同屏看不出两种画法。

### color_light_coherence　权重 25　核心维

- 看哪里：F3（对白中景 · 1280×720）角色受光面与铺地受光面；F1（俯视全景 · 无 UI · 1280×720）角色与地面
- 3 分：角色高光方向与场景主光不一致，角色暗部没有环境色，两者像被分别打光。
- 4 分：角色与场景受同一主光支配，受光面朝向一致，角色暗部带场景环境色。

### grounding_occlusion　权重 20　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）角色脚下 y=626–642；F4（树后低角 · 1280×720）角色与树的前后关系
- 3 分：角色底缘下 12px 带比同 x 更下方 30px 暗 81/255（85.4 对 166.4），说明阴影存在且是平滑渐变；但阴影是一团模糊椭圆，不随脚形，且角色底缘是贯穿全身的平直硬切，看不到脚。
- 4 分：阴影贴合脚形并随动作移动，底缘由脚或裙摆的自然轮廓取代硬切；树前树后遮挡正确。
- 实测：脚下带 85.4 / 远处 166.4 / 差 81.0；底缘 y=627 为突变的水平线

### focus_readability　权重 15　核心维

- 看哪里：F1（俯视全景 · 无 UI · 1280×720）全图明度分布；F2（同机位 · 有 UI · 1280×720）有 UI 时
- 3 分：画面最亮的部分不在角色附近（实测最亮 10% 像素重心在屏高 34.9%，落在背景带），角色不是第一落点。
- 4 分：角色所在区域是画面最亮或对比最高处，UI 出现后仍成立。
- 实测：最亮 10% 重心 34.9% 屏高

### world_style_coherence　权重 15

- 看哪里：F2（同机位 · 有 UI · 1280×720）UI 与场景；F5（告示板近景 · 满 · 1280×720）道具与场景
- 3 分：道具、场景、UI 三套视觉语法并存，比例与笔触互不呼应。
- 4 分：道具、场景、UI 共用同一套比例、笔触与明度规则，换场景仍成立。
