> 这份文件只回答一件事：**要画成什么样，才算画对了。**
> 上游依据：主方案 **v13**（平面）、陈设 **v06**（物件）、风格 v01（色板与光）、实机审计 v02（形态）、一致性审查 **v02**（数字）。

> 新增"视口与跟随"一节、角色层规范；验收从 13 条扩到 **16 条**（+G7 边界、+G8 衔接、+A1 角色层）。

## 1. 一句话目标

**一张 1920×2490 的整图，把核心区 240×190、引道 60、试车间 170×130 一次画完；55° 正交俯视、上南下北、无屋顶，用三角洲实机的 12 色。
运行时用 1080×1620 的视口在这张图上跟随角色滑动，视野 135×247 m。**

## 2. 画布与坐标（唯一口径）

| 项 | 值 |
|---|---|
| 世界范围 | x 0..240，y −190..190（**240 × 380 m**） |
| 核心区 | x 0..240，y 0..190 |
| 引道 | x 180..204，y −60..0 |
| 试车间 | x 70..240，y −190..−60 |
| 显示比例 | **8 px/m** |
| 纵向比例 | 8 × sin55° ≈ **6.55 px/m** |
| 整图 | **1920 × 2490 px** |
| 视口 | **1080 × 1620**（在 1920 高的画布中垂直居中，上下各 150 px 给 UI） |
| 视野 | **135 × 247 m** |
| 跟随余量 | 横向 840 px（105 m）、纵向 870 px（109 m） |
| 换算校验 | 380 × 8 × 0.8192 = **2490.4** → 取 **2490** |

> 任何改动先过这一关：**横向 240 m 必须正好 1920 px**。比例一变，整张图重画，不要局部缩放。
> 8 px/m 不是随便定的：整图必须比视口大，否则"走到哪看到哪"无从谈起（4.5 px/m 时整图比视口还矮 219 px）。

### 2.1 像素换算（程序侧直接用）

```
px = x * 8
py = (190 - y) * 8 * 0.8192          # = (190 - y) * 6.5536
```

| 关键点 | 世界坐标 | 整图像素 |
|---|---|---|
| 核心区北墙 | y = 190 | py = 0 |
| 南出口 | y = 0 | py = **1245**（整图纵向 50%） |
| 试车间北门 | y = −60 | py = 1638 |
| 撤离点 | y = −180 | py = 2425 |
| 试车间南墙 | y = −190 | py = 2490 |
| 西墙 / 东墙 | x = 0 / 240 | px = 0 / 1920 |

## 3. 相机（必须在出图前定死）

| 项 | 值 | 说明 |
|---|---|---|
| 投影 | **正交（orthographic）** | 透视会让五栋楼的墙不平行，拼图必歪；这条不能改 |
| 俯角 | **55°**（可 55–60，定一个就不再动） | 低于 50° 会挡后排，高于 65° 会变成平面图 |
| 方位 | 相机在**北侧、朝南**看 | 画面**上南下北**，玩家向南跑 = 朝画面上方 |
| 旋转 | 欧拉 (55°, 0, 180°) | Blender：默认朝 −Z，绕 X 抬 55°，再绕 Z 转 180° 指向 −Y |
| 相机位置 | (120, 700, 1000) 附近，只影响裁剪不影响比例 | 正交下距离无所谓 |
| ortho_scale | **240**，`sensor_fit = HORIZONTAL` | 保证横向 240 m 正好 1920 px |
| 分辨率 | master **3840×4980**，运行时 **1920×2490** | 2× 渲染再降采样，抗锯齿更干净 |
| 裁剪 | 必须一次渲完整图，**不许分块拼接** | 分块会在接缝处出现光照差与阴影断头 |

> **这一张图就是全部。** 因为是跟随不旋转，整图渲一次即可，不需要多角度图集。
> 代价：玩家不能转视角，靠小地图与指向箭头定位。

## 4. 视口与跟随（运行时，出图不涉及但影响验收）

| 项 | 值 |
|---|---|
| 视口尺寸 | 1080 × 1620 |
| 跟随中心 | `cam_py = (190 − y_char) × 6.5536` |
| 视口顶 | `clamp(cam_py − 810, 0, 2490 − 1620)` |
| 水平跟随 | `clamp(x_char × 8 − 540, 0, 1920 − 1080)` |
| 死区 | 角色在视口中央 ±60 px 内移动时，镜头不动 |
| 缓动 | 0.15 s，线性插值，不用弹簧 |
| 旋转 | **无**。相机朝向恒定，不做转视角 |
| 小地图 | 180×180，**北朝上**，独立于主画面 |

**三处跟随边界（必须专测）：**

1. **南出口**：py = 1245 恰在整图纵向 50%，跟随到这里时核心区与引道**同屏**——全程唯一的两区同屏时刻，要保证引道不挡出口视野。
2. **东西边界**：贴西墙时只能看到 x 0..135，**看不见东侧蓝室**。小地图是必需项，不是可选项。
3. **撤离点**：py = 2425，视口顶只能到 870，会被顶边卡住，角色停在画面下方约 1/3 处——这是正常表现。

| 层 | 内容 | 备注 |
|---|---|---|
| L0 地面 | 混凝土大板、草地/硬化分界、围墙外压暗 | 分格 3×3 m，缝深 15% |
| L1 体块 | 四室墙、庭院、**两间前厅**、**两条封闭钢廊（A 16 m / B 27 m，宽 6 m）**、引道、试车间防爆墙 | **全部无屋顶**；墙高见第 6 节；钢廊是实心墙带，两端才有开口 |
| L2 大件 | 离心柱+吊舱、浮力池+3 压力舱、蓝室坑+双机械臂+卫星、黑室圆舱门+筒拱、总裁玻璃盒+**南向挑檐**、龙门吊 | 这七件决定"像不像" |

## 6. 墙高（按房间，不要统一）

| 区域 | 墙高 | 理由 |
|---|---|---|
| H1 离心 | 9 m | 观察窗带 4.5 m，上方还要留白 |
| H2 浮力 | 10 m | 二层办公舱 3.2 + 池深 6.5 |
| H3 蓝室 | 7 m | 环廊 4.5 + 栏板 1.1 + 余量 |
| H4 黑室 | 10 m | 筒拱 8 m |
| 总裁 | 4.5 m（盒） | 玻璃盒本身的高度 |
| 试车间 | 9 m | 防爆墙 |
| 西院 / 东院 / 中庭 | 6 m | 小尺度，压住遮挡 |
| 最外圈围墙 | 6 m | — |

> 遮挡估算：墙高 × 0.7 = 墙后被压掉的进深（55° 时）。9 m 墙压 6.3 m，10 m 墙压 7 m。
> 这就是为什么小院只能 6 m——再高就把对面门口吃掉了。

## 7. 必须画对的七个识别点

| # | 房间 | 识别点 | 画错的后果 |
|---|---|---|---|
| 1 | H1 | **一条 14 m 横置吊舱，斜 20°** | 正放会读成走廊，整间房失去意义 |
| 2 | H2 | **矩形深池里三个白圆柱** | 画成圆池就变成另一间房 |
| 3 | H3 | **9 条水平蓝光带 + 金色太阳翼** | 少了蓝光就没有"蓝室" |
| 4 | H4 | **Ø12 圆形舱门 + 整面绿墙** | 绿是全区唯一的绿，不能省 |
| 5 | 总裁 | **40×30 玻璃盒 + 南向 3 m 挑檐 + 东西各一道门** | 挑檐画丢，就只剩一块平玻璃；两门若画到同一面，就失去"两条独立入口" |
| 6 | 试车间 | **9 m 墙 + 场中央集装箱挡住终点** | 挡不住就失去"找出口"的体验 |
| 7 | 全场 | **一栋楼一个色相**（青/青黄/蓝/绿/铜） | 混色就读不出分区 |

## 8. 光（照抄，不要自由发挥）

| 项 | 值 |
|---|---|
| 天空 | `#D8DEE0` |
| 主光 | 5600–6000K，高度角 55–65°，偏南 |
| 投影 | 0.6–0.8 倍物高，**硬边** |
| 环境光 | `#8FA3B0`，18–22% |
| 室内补光 | 4000K，均匀，不做出光晕 |
| 暖光 | **只在总裁**（2700–3000K） |

> **光影是烘死的。** 角色是运行时贴上去的，所以角色**不能吃场景光照**——
> 必须自带一个固定方向的椭圆假阴影（偏移 −6, +8 px，不透明度 35%，软边 4 px），
> 方向与 55° 主光一致。这条不做，角色会像贴纸一样浮在地面上。

## 10. 禁止清单（出现即退回）

1. 屋顶（**唯一例外：总裁玻璃盒的透明顶**）。
2. 门楣 / 门框上沿（门洞必须是通高缺口）。
3. 锈、水渍、杂草、随机污渍（**唯一例外：试车间墙脚 1.5 m 水渍**）。
4. 小于 **1.5 m** 的独立建模构件（8 px/m 下不足 12 px，改画贴图）。
5. 屏上小于 24 px 的文字（8 px/m 下约 3 m）。
6. 橙色 > 2%、绿色 > 8%、蓝光出现在 H3 以外。
7. 透视投影、鱼眼、倾斜地平线。
8. 圆角（金属件 R≤0.05，混凝土不倒角）。
9. **分块渲染再拼接**（接缝处光影必断）。
