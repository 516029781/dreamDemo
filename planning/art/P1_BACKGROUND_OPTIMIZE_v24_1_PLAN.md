### 成立、且比原方案更狠的

- **光在左上侧逆**（影朝右下，台阶踢面全暗/踏面全亮 79–88 vs 155–158），仰角约 25–30°；
- **草的内部反差**才是关键：尖端 210–250（带辉光）、中段 150–200、根部 70–120，σ 40–55；
  不是"比桶壁亮 40"——那是把草做成一块均匀亮斑；
- **前期/后期占比**：后期（辉光/雾/景深/暗角/颗粒/分级）约占"像不像"的 **35–40%**，原方案一个字没提；
- **画面四边都靠实体切出**，不止左上树冠；
- **石板要逐块不同**（每块 5–15 灰阶色差 + 磨痕 + 污渍），一张贴图平铺必然假。

### 审查报告里**错**的一条（已核实）

技术审查称"`M01W` 水面 y15.30–22.50 仍在场景、铺满 v4.6–14.1"。
**实测：场景里已无任何 `M01` 命名的对象**（`s1_pool.py` 已删），可见网格 603 个。
v5–14 那块米黄来自 M02 景片本身，不是 M01W。因此"重画景片没用"的结论不成立。

## 三、修订后的做法

### 分工原则（保留 v24.1，是对的）
要不要被别的物体遮挡 → 要，用 3D；不要，用卡片。

### F0 光色与后期（第一步，半天）
之所以排第一：**所有分层验收都在光下量**，光不正，量什么都是错的；且它最便宜、见效最快。

- 主光：方位画面 **10–11 点**（左上偏后），仰角 **25–30°**，影长/物高（**世界空间**）2.0–2.4；
- 天光：偏蓝（色温 ~11000K），负责所有阴影里的冷；
- 补光：右侧低角度、**冷**、弱（只提亮背光面，不改色相）；
- 合成器：`Glare(Bloom)` 阈值 0.85 → 草尖/窗洞外溢；按深度做雾；轻景深（只锐中景）；暗角 −12%；颗粒 3%；分级亮部橙/暗部青。
- 验收：与参考**同时缩到 160 px 并排**，一眼分不出哪张是渲染 → 才进下一步。

### F1 前景大台阶（1 天）—— 替换 v78–100 那块空白立面
- 现有 `Landing front fascia right` 通宽立面拆掉，改成 **10 级台阶**（踏面 0.34 / 踢面 0.16，总高 1.6 m）；
- 横向占 u0.14–0.62（x −4.6…3.2），其余部分保留矮墙 + 栏杆；
- 两侧各一道"立柱 + 双横杆"栏杆，立柱间距 1.6 m；
- 台阶从广场（z 0.035）下到下层地面（z −1.3）；
- **验收**：v78–88 的 σ ≥ 40（现在是 3–5）；影长/物高在石板上可量到 1.8–2.4。

### F2 下沉天井（1 天）—— 替换 v40–50 那排箱子
- 位置：u0.60–0.75 → 世界约 x 1.6…4.4、y 0.6…2.6；
- 做法：广场上开一个矩形下沉口（深 0.9 m），四周 0.35 m 矮墙，墙顶一圈**深红棕压边**（基色 92,52,42，比石板暗 40–60）；
- 近侧一道金属护栏；内部底面用天光照明（背光）；
- 原来那排集装箱/罐体**只保留 3–4 件**，作为天井边上的设备，其余删除；
- **验收**：天井内明度 70–95、压边明度 55–70；洞口的斜向四边形在画面上成立（不是横带）。

### F3 剪影封边（半天）
四条边都要有实体切出，不是暗角：
- 左上：树冠加厚（叶卡），压到 v0–30；
- 上中：远山脊 + 雾（软、低对比、被塔打断），**不留未打断的硬直线**；
- 右：圆塔 + 草堆从 v0 压到 v62，下接矮墙栏杆；
- 下：台阶切出画面；左：小车 + 铁网 + 三角旗。
- **验收**：Hough 检测长度 > 30% 画幅的直线数量 = 0（现在 v14 那条会被检出）。

### F4 草与树卡片化（1.5 天）
- **两种草分开做**：
  - 高疏剪影草（塔顶/墙头，1–1.5 m，能透出后面）—— 300–400 张/池；
  - 密实矮草（贴墙种）—— 200–300 张/池；
- 单卡 512×256，深根（70–120）/ 中段（150–200，S 0.45–0.55）/ 亮尖（210–250，S 0.25–0.35）+ 亮尖 15% 自发光；
- **验收**：草区 σ ≥ 45；亮尖−暗根跨度 ≥ 120；草区饱和度比桶壁高 0.35–0.45。
- 卡片必须**合并成单 mesh**（每池一个），否则 2400 个物体把 blend 从 203 MB 拖到不可用；
  Cycles 的 `transparent_max_bounces` 从 8 提到 24，否则后排被切掉出破洞。

### F5 石板做旧（半天）
- 每块板独立色差（vertex color，±8 灰阶）+ 接缝加深 + 8–12 条裂缝 + 污渍斑 + 边棱 bevel 0.02 + 微抖动（不是数学直线）；
- 撒 30–50 片落叶卡片（**保留投影**，否则没有体积）。
- **验收**：σ ≥ 45；32 px 窗内局部对比度分布与参考的 KS 距离 ≤ 0.15。

### F6 景片收口（半天）
- M02/M03 **发光强度统一为 1.0**（现在 1.72 / 0.89，这是接缝的直接来源）；
- 贴图值 ≈ 渲染值，作者可控；
- **验收**：v6、v10 两行一阶差分 |Δ| < 12。

## 四、验收口径（替换掉 IoU）

**客观（可脚本化）**

| 指标 | 阈值 | 说明 |
|---|---|---|
| 硬边地标逐行边缘位置 RMS | ≤ 8 px | 只用 3 个地标：塔左缘、池沿外环、台地远缘/踏步起始 |
| bbox 尺寸误差 | ≤ 2% | 同上 |
| Hough 长直线（>30% 画幅）数量 | = 0 | 直接替代"接缝一阶差分" |
| 8 px 模糊后 SSIM | ≥ 0.82 | 只看大块明暗布局 |
| 色温图（R−B）空间相关 | ≥ 0.75 | 冷暖分布是否一致 |
| 梯度幅值直方图 KS 距离 | ≤ 0.12 | 边缘软硬 |
| 冷色占比（现口径） | 0.25–0.50% | 保留 |

**主观（必须写进门禁）**
- 缩略图测试：缩到 160 px 并排，能否一眼分出渲染；
- 眯眼测试：模糊到只剩大块，重心位置是否一致；
- 去色测试：转灰度后层次是否还在；
- 盲测：5 个没参与的人并排看，问"哪张是参考"，**正确率 < 60% 才算过**。

> IoU 不再用：整幅层恒等于 1，水池层上限 0.12–0.45，0.90 又宽松到能容忍 20–48 px 平移。

## 七、开工前体检补正（2026-11-01 02:30，射线实测）

四条实测结论，都改执行参数，不改方向。

### 1. 台地远缘不是"被压住"，是要做成下坡

- `T01 | far retaining wall` 与 `T01 | far retaining coping` 的 z 范围**都是 0.02**，高度为 0——那不是墙，是一片薄片。
- 台地 `Rear service terrace ground` 在 y=15.25 结束，z 顶面 0.06。
- 射线逐层：v2% 命中 M02 景片（y34.5, z−1.8）；v8–14% 命中 54 个 `P1 bank | shrub`（y14, z0.3–1.0，**同一 y 平面排成一条**）；v14% 之后才是台地顶面。

所以"那条线"= 台地顶面边界 + 灌木带的底边**重合**。靠加实体去盖是治标：
**改法**：F3 把台地远缘 y15.2→y24 做成 **−10°～−12° 的下坡干草坡**，灌木按坡度重排（前低后高、y 错开 0.4–1.2 m，不再同一平面），水塘留坡脚，景片只负责 y24 之后的山脊。线自然消失，因为那里变成了坡。

### 2. F2 天井位置已占用，不是空的

x1.6…4.4 / y0.6…2.6 内有 **36 个对象**：`P1 yard | crate R1/R2/R3`（z 0…1.11）、`P1 yard | kerb B`（z −0.02…0.78）、石板与 pennant。
**改法**：先删这 3 箱 + kerb B，再开洞。原文"已核实该处只有草与栏杆"作废。

### 3. 前景已有 3 级孤立台阶，高度不连续

- `Broad worn curved stair tread 06/07/08`：x −4.47…−1.83，y −3.63…−2.94，z −1.25…−0.81，**只有 3 级、进深 0.7 m**。
- `Landing front fascia left` x −10.4…−4.55 / `right` x −1.75…3.54，z −0.73…−0.08。
- 上层平台 z −0.1（y −4…3），下层地面 z −1.45（y −12.5…−4），**落差 1.35 m 却只有 3 级**——这就是"读不出用途"的根源。
- **改法**：F1 在 x −4.4…3.4 重建连续 10 级：z 0.06→−1.45，每级高 0.151 / 深 0.34，进深 3.4 m（y −0.4…−3.8）；左右立面**按级退台**，不做整块竖墙；现有 3 级踏步与两段 fascia 在施工范围内删除。

### 4. 压边只能用近处的树

画面 v=0 在 y=15 处只对应到 **z=1.99**——y15 处高于 1.99 m 的东西全部顶出画外。
所以"左上树冠压到 v0"必须用**近处**的树：现有 `P1 broadleaf | Poly Haven Tree Small 02 LOD1`（y1.3…8.1，高 6.68，z 顶 6.89）正好可用。远处抬高无效，只会被裁掉。

## 八、一句话

原方案**方法论对、部位错**：谷不是墙、前景不是石板、验收不该用 IoU、光色不该放最后。
修订后先补光色后期（拿到判断基准），再动两个真正的主角——**前景十级大台阶**和**广场下沉天井**；
背景那条线不是盖住的，是**把台地改成下坡**。
