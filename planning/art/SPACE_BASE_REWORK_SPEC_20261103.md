## 2. 用户定案（四条，必须照做）

### 2.1 四室直接围合，每处 2 个门，无中间区域

- 四室围成一圈：**离心（西北）↔ 浮力（西南）↔ 黑室（东北）↔ 蓝室（东南）**，中央是总裁塔。
- **相邻两室之间的连接处各有 2 个门**（双向双通道），推门**直接进入下一室**。
- **取消**：四条环廊、中央 100×50 实心设备体、南花园带夹层、西院/东院/南北中庭——一律不做。
- 四室之间的间隙压缩为**门洞 + 短通道**（建议 6–10 m），不再是 50–100 m 的"环廊"。

### 2.2 总裁悬空，浮力与黑室各一部独立爬梯

- 总裁室在四室围合的**正中央，悬空**（不落地、不坐设备体）。
- **浮力室、黑室各有一部独立爬梯**，从室内直达总裁。
- 只有这两部爬梯能进总裁；离心、蓝室没有入口。
- 取消"9 m 实心设备体 + 检修廊 + 梯井"这套做法。

### 2.3 撤离路线要长

实测（PhysX 碰撞几何 + BFS 可通行网格，2 m 格，8 连通）：

| 起点 | → 南侧撤离区（净行走距离） |
|---|---|
| 黑室（东北） | **326–380 m** |
| 浮力（西南） | 254–374 m |
| 蓝室（东南） | 226–273 m |

**当前方案黑室→丢包点约 296 m**，比真实短 30–80 m；更关键的是**形态太直**（黑室→花园→引道→试车间几乎一条直线南下），缺少真实地图里"穿过核心区外一整片外围区"的层次。

**返工要求**：
- 黑室→丢包点 **≥ 350 m**，全程至少 **3 次转向**；
- 核心区南缘到撤离区之间保留一整片**外围过渡区**（≥ 100 m 进深），不能一出门就进试车间；
- 丢包点仍是**单独一块**（独立场地的一角，4×4 黄框 + 终端），不与核心区直接相邻。

### 2.4 室内陈设密度（推荐值）

8 px/m、一屏 135×247 m 的预渲染下，判断标准不是"总件数"，而是**8 px/m 下仍能辨认轮廓的中大型物件数**：

| 级别 | 尺寸 | 每室数量 | 作用 |
|---|---|---|---|
| L1 识别件 | 5–15 m | **4–6 件** | 决定"这间房像不像"（离心立柱+吊舱、深池+压力舱、机械臂+卫星、圆舱门+行车） |
| L2 中件 | 1.5–5 m | **18–25 件** | 填满空间、形成密度（控制台、货架、柜体、管道、栏杆、集装箱） |
| L3 贴图件 | <1.5 m | 不限 | 标线、铭牌、污渍 |

- **每室实体件 22–31 个，四室合计 90–124 个**；加总裁、通道、试车间，全图约 **220–280 个**。
- **密度红线**：每 200 m² 至少 1 个中大型物件（70×70 房间 ≈ 24 件起）。
- 当前 v02 约 256 件但分布偏墙边、地面大面积空置，是"简陋"的直接原因。

## 3. 新核心区拓扑（用于替换 v1.3 §2/§3）

```
                   北
        ┌──────────┬──────────┐
        │ 离心 H1  │ 黑室 H4  │
        │ （西北） │ （东北） │
        │  Ø40圆厅 │  Ø12舱门 │
        ├══ 2门 ══╪══ 2门 ══┤
        │ 浮力 H2  │ 蓝室 H3  │
        │ （西南） │ （东南） │
        │  矩形深池│ 双机械臂 │
        └──────────┴──────────┘
             中央：总裁（悬空）
             爬梯：浮力 ↑、黑室 ↑
```

- 四室两两之间：**各 2 个门**，推门直达。
- 中央：**总裁塔（悬空）**，仅浮力/黑室两部爬梯可达。
- 四室之外不再有任何"环廊/中庭/花园"中间层。
- 撤离：从黑室（东北）出发，需**绕行核心区外围**向南，最终到达独立丢包点（≥350 m、≥3 次转向）。

## 4. 返工步骤

1. 按 §1 修正方位（南北镜像），按 §2.1 重画核心区拓扑（四室围合 + 每处 2 门 + 去中间层）。
2. 按 §2.2 重做总裁（悬空 + 两部独立爬梯）。
3. 按 §2.3 重排撤离路线（≥350 m、外围过渡区 ≥100 m、丢包点独立）。
4. 按 §2.4 重做陈设（每室 22–31 件，L1 4–6 件）。
5. 重渲染，走 harness 全流程（G1–G8 / W1–W2 / S1–S7）。
