**两条反直觉的结论**（都由数据得出，不是印象）：

1. **广场的问题是"平"不是"暗"**：均值 134.4 与参考 142.7 只差 8，但标准差差 19.3（36.5 vs 55.8）——参考的地面被投影、堆放、裂缝切碎了，我们的是一整块。
2. **背景带的问题是"跨度大、细节少"**：标准差反而比参考高 10.5（50.7 vs 40.2），但边缘密度低 10（21.9 vs 31.9）。说明水与岸的明度跳得太开、而画面内容太空。**B2 要做的是压暗 + 加密，不是加强对比。**

**重要结论**：整条背景带只有 **0–17%**，水面只有 **4 pp**。
v1–v3 里"水面占 10–22%、挡墙在 22–24%"的分配是错的——广场尽头在 y 15.2（36 m），投影就在 15%，不存在 22% 的水面。**不要再把水面往画面下方挪。**

## 2. 参考图的实际做法

放大裁切（`v22/ref_crops/`）逐块看完，六条：

1. **3D 白模 + 手绘贴图**。透视严格、阴影方向一致 → 几何是 3D；地面的块状色差和走向明确的裂缝是画上去的。
2. **单一强方向光**，暗部压到近黑。格栅内部、台阶下方几乎全黑。
3. **背景是被近景"框"出来的**：左树冠压左上、右草池压右上，中间才露远景。背景不是一条带，是**窗口**。
4. **景深明显**：角色清晰、背景虚化。
5. **工业元素是设定的一部分**：橙色叉车、黄色锥桶、金属格栅、管道、风车、彩旗全都有。
6. **后期**：暖调 + 颗粒 + 轻微暗角。

## 4. 执行步骤

每步都遵循同一个模式：**改 → 渲染小图 → 采样像素/射线 → 不达标按给定步长调 → 达标才进下一步**。
不写"应该多少米"，只写"要测到多少值"。

### B1 · 水面 ✅ 已完成（本节保留，作为后续回归基准）

**问题**：水面是 `(58,60,63)`，比岸线暗一半，读起来是黑缝而不是水。参考里水面比岸**亮**，是画面里唯一的冷光区。

| 项 | 做法 |
|---|---|
| 对象 | 材质 `M01W water`（Base Color 目前接 `M01_watertex.png`，均值 81） |
| 做法 | **断开贴图**，Base Color 改常量；贴图在这个高度（4 pp）本来就看不见，只贡献错误明度 |
| 初值 | `(0.30, 0.29, 0.26)` 线性 ≈ sRGB `(150,148,142)` |
| 保留 | Roughness 0.86、IOR 1.03、Specular 0.05（已确认哑光正确，水面不该有强反射） |
| 迭代 | 渲 24 spp / 50% → 采样 v 11–13% 中心三列 → 目标 **140–170**，未到 ×1.12，过了 ×0.90 |
| 收尾 | 达标后加一条极轻的横向明度带（±6）避免死板，写入贴图或直接做在色上 |
| 验收 | 水面均值 140–170 **且** 比岸线亮 **≥ 8**（D3 同时解决） |
| 回退 | 若水面比天空还亮（>190）→ ×0.85 |

脚本：`preflight/b1_water.py`（已跑通，2 轮收敛，落 `B1_LOCK.json`）。
**回归基准：改动灯光或曝光后，水面均值必须仍在 140–170、比岸线亮 ≥ 8。**

### B2 · 背景带分层（M02 / M03 重绘）

**目标**：把 0–9% 这块均匀土黄，改成三段可辨的层次 —— 树线、对岸草坡、水边暗边。

| 子项 | 做法 | 验收 |
|---|---|---|
| B2-0 | **先校验 UV 方向**：在 `M02_bank.png` 第 10% 行画 3 px 洋红横线 → 渲一张 → 看洋红出现在画面高位还是低位 → 记录到 `B2_UV.json` | 方向锁定后才允许正式绘制 |
| B2-1 | M02 重绘：v 0–2% 树线剪影（12–18 簇，边缘 1.5 px 软化）→ 2–6% 干草坡（明度 165→120 纵向渐变 + 30 处不规则斑块）→ 6–9% 水边暗边（明度 80–95） | 三段相邻明度差 **≥ 25** |
| B2-2 | 树线剪影**只画在贴图上**，不做低模（可见区仅 5 pp，低模与贴图分不出来，而远处高物体顶部必然出画） | — |
| B2-3 | M03 只在 v 0–1.5% 可见，做成暖灰天光（明度 150–160），不做远山（无空间给它） | 顶部不出现灰蓝 |

**注意**：M02/M03 当前各放大 1.08 倍做过覆盖（`B0C_FIX.json`）。重绘贴图**不要改几何**，避免破坏这层余量。

### B8 · 石板贴图手绘（D2/D4 的本源）

**现状**：噪声 + Voronoi，边缘密度 17.8。参考靠**块状色差 + 有走向的裂缝**做到 22.6。

| 子项 | 做法 | 参数 |

## 5. 顺序与卡点

```
阶段一 · 结构（形状与空间）
  B0 ✅  几何 6 修        → raycheck 三切片全过
  B1 ✅  水面明度         → 166.6 / 比岸线 +51.9
  B2     背景分层（压暗+加密）→ 均值 90–105、边缘密度 ≥28、标准差 40–48
  B3     圆筒比例         → 直径 2.7–3.0、顶部 v ≥ 0.05
  B4     树冠下垂         → 下缘 v 23–26%
  B5-0   逐灯贡献测量      → 定出主光（B5_LIGHT_SOLO.json）

阶段二 · 内容与手绘
  B7     广场内容         → 标准差 ≥50、边缘密度 ≥21.5
  B8     石板贴图         → 边缘密度 ≥21.5、≥8 条裂缝、无接缝
  B9     设备构架         → 层级 ≥3、转折 ≥12、不侵入 v<17%
  B10    草冠曲面         → 覆盖率 ≥90%、无 >2% 镂空

收尾（必须最后）
  B5     定光 + 景深       → 暗部 ≤45、影长/物高 2.0–2.5、CoC ≥2px
  正式图 48spp            → raycheck 三切片 + 二级像素全过
  B6     后期             → 整体均值 120–145、B/R ≤1.25
```

**为什么 B1 在 B2 前面**：水面原来是黑的，背景画得再好也会被这条黑缝切断。
**为什么 B3/B4 在 B5 前面**：改了尺寸和冠层体积，遮挡关系会变；先定形状再定光，否则光要调两遍。
**为什么 B6 从阶段一挪到最末**：旧版把后期放在阶段一末尾，但阶段二还要加堆放、换贴图、改设备——这些都会改画面明度与色偏，后期参数全部作废。**后期只能做一次，且在最后一帧上做。**
**为什么 B5 也挪到最后**：B5-0 的逐灯测量只需一次（阶段一末尾），但真正的**定光**要等形状全部到位。先测归属、后定强度，避免光调两遍。

### 7.3 到 85 的三个前提（不回避）

1. **B8 必须真做**。贴图若仍是"程序化 + 噪点"，广场边缘密度上不到 21.5，天花板停在 **82–83**。
2. **B9 必须成构架**。若只是加几个盒子，物件维度封顶 3.4，总分扣约 0.75。
3. **B10 必须有曲面**。分离草束在近景会被看穿，植被封顶 3.1。

三者任一失败，85 不成立。这是本方案唯一不能靠参数兜住的地方，也是它与前几版的根本差别——前几版把这三条写成"不在范围内"，等于放弃 85。

### 7.4 一条可选加分项（不影响上表）

参考是厚涂笔触，Cycles 输出仍是照片级。若还要更接近，可加 **B11 笔触后期**：把成图过一层方向性笔触滤镜（强度 15–25%，沿光方向），只改输出不改场景，风险低。
**不计入 85 的评分依据**，因为它是"看起来像"，不是"本身对"。
