## 3. 它差在哪：三条实测，不是感觉

把参考图和 v02 成品都归一化到 600 px 宽，切成 6×4 网格，每格算平均亮度：

**参考 t084s（每行 6 格的平均亮度）**

| 行 | L 均值 | 内容 |
|---|---:|---|
| r0（顶） | **99** | 树冠压满，暗暖 |
| r1 | **94** | 枝叶、设施、围栏 |
| r2（中） | **154** | 受光平台，最亮 |
| r3（底） | **115** | 前景台阶，处在阴影里 |

**v02 成品**

| 行 | L 均值 | 内容 |
|---|---:|---|
| r0（顶） | **125** | 一条平的冷灰远景带 |
| r1 | **122** | 物件散落，空旷 |
| r2（中） | **155** | 受光广场 |
| r3（底） | **157** | 空广场，和中间一样亮 |

### 三条差异

**① 亮度结构反了：参考是"暗—亮—暗"，我们是"灰—亮—亮"。**

- 顶部：参考 99，我们 125 → **该暗 26 级**
- 底部：参考 115，我们 157 → **该暗 42 级**
- 中段：参考 154，我们 155 → **已经对齐**

三段对比度：参考 顶↔中 = 55、中↔底 = 39；我们 30 和 **−2**（底部比中间还亮，等于没有前景）。

**这意味着不需要"整体调色"**——中段是对的，只要把顶部和底部压下去，画面立刻有纵深。

**② 顶部该是暖叶，我们给了冷灰。** 参考左上角 `#5f493e`（R95 G73 B62，R−B=33，暖暗）；我们左上角 `#777d7e`（R119 G125 **B126，B>R，是冷灰**）。就是 v02 自评里说的"远景被硬色带取代"——实测证实：那条带子不仅亮，而且**色相错**。

**③ 受光面不够暖。** 参考中段受光格 `#c6b19b`（R−B=43）；我们 `#ada193`（R−B=26）。差 1.6 倍色温，所以画面显得"干净但没阳光"。

### 局部材质语言（看图确认）

- **树冠**：现在是一片片深褐色硬块直接贴在粗枝上，叶簇彼此分离、没有透空层次、没有受光面。参考是连续的、细碎的、被光照透的金褐团块，枝干大部分被叶子挡住。→ 这是六个"rework"里最伤观感的一项。
- **铺装**：石板尺寸统一了，但缝是均匀深色细线组成的**规整网格**，表面没有低频色差、没有边缘磨亮、没有污痕堆积。参考的缝被阴影和脏污部分遮住，石板之间有肉眼可见的明度差。
- **台阶与栏杆**：v02 的台阶侧面是一整块近黑的面，栏杆柱子底部没有接触阴影，看着像"浮在铺装上"。

## 4. 方案：三步，每步可量化验收

原则：**不动工具链，只动画面。** 每一轮 41 秒，允许一天试 20 个机位。

### 第一步 · 构图标定（半天）

不做审美判断，先把参考图的分区比例量出来对齐：

| 锚点 | 参考的实际占位 | 验收目标 |
|---|---|---|
| 平台边缘（铺装 ↔ 远景交界） | 落在画面 y ≈ 58% | y = 58% ± 3% |
| 前景台阶 | 占底部 22–28%，偏左 | 底部 22–28%，左偏 |
| 主树冠 | 压住左上角，越出顶边 | 顶部 0–18% 全宽有叶 |
| 圆筒草池 | 贴右边框中段 | 右缘 x > 78% |
| 远景带 | 只占 12–15% 高度 | 高度 ≤ 16%，且不含硬直线 |

**机位调整**：俯角从当前 29°（rotX 1.0587 rad）降到 **20–22°**，机位前移 6–8 m，焦距 53 → 45–48 mm。目的：让广场从"占三行"缩到"占一行半"，把画面还给前景台阶和树冠。

**验收**：6×4 亮度网格与参考**每格差 < 15**（当前顶部差 26、底部差 42）。

### 第二步 · 光比（1 天）

- 主光方向和仰角按参考的阴影反推（阴影朝向画面右下，说明主光在左上偏后上方）；
- **提高 key/fill 比**，压 ambient——现在环境光把阴影抬平了；
- 台阶、花池、栏杆底部补 **AO + 接触阴影**，解决"浮在铺装上"；
- 远景不用"色板"，改**雾化 + 受控景深**（v02 已经有 f/4.2 + 31.5 m 对焦，方向对，只是没作用到远景）。

**验收**：三段亮度 = 顶 99±8 / 中 154±6 / 底 115±8；受光面 R−B ≥ 40。

### 第三步 · 材质语言（1–1.5 天）

1. **树冠母版重做**：主干 → 一级枝 → 二级枝 → 少量三级枝；叶片换成**椭圆/披针形叶簇**，沿枝分布并留不规则透空；先做黑白剪影检查（v02 的球形团块和"云墙"都是剪影没过关）。
2. **草池改成三种可编辑草簇**：低密根团、侧倾弧叶、上扬细穗；按池边和风向手工摆，小比例散布填缝。50% 缩图应读到连续草冠，而不是一束束独立尖草。
3. **石板改成一套大板 + 低频色差 + 边缘磨亮 + 稀疏污痕**；缝宽按屏幕像素统一，缝底抬高避免黑沟。
4. **远景建三层**：近水缘（有反光）、浅暖岸带（低对比）、树/建筑剪影（低饱和）；层间用空气雾化衔接。

**验收**：四个组合（地板 / 树 / 草 / 全画面光色）全 `pass`；六维各 ≥3/4，总分 ≥90。

## 6. 与 3D 线的关系

- **现在只做静态图。** 包体、draw call、材质合并、烘焙这些账在本方案里不存在，不用管。
- **如果以后要转可交互**：静态图可以当 2.5D 的分层背景（前景台阶 / 中景平台 / 远景雾化，三层分开出图），角色走 Spine 面片——这正是方舟本体"3D 场景 + 2D 角色"的低成本版本。
- **建议顺序**：先把静态图的观感打到 ≥90，定死美术方向；3D 化再决定要不要做。反过来做（先 3D 再调观感）会重演前两周那轮返修。
