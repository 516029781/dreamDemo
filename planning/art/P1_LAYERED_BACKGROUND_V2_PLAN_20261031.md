## 2. 目标画面：以 P1 可观察事实为准

画面从下往上读为：**暖浅石板与台阶 → 有连接的设备/步道/栏杆 → 真实近岸浅沿与暗侧壁 → 局部蓝灰水面 → 少量暖浅对岸 → 更软的远树与暗暖空气层**。左树和右侧圆筒草池遮断远景两端。蓝水在中央设施后方，只从间隙出现；它不是画在地上的完整池形。P1 可见冷色远景的约略外框为 `u=.30–.54, v=.13–.27`（左上原点、归一化坐标），**这是锚区，不是必须填满的矩形或已分割的精确水形**。

P1 的左上深褐树冠、右侧金褐草冠、中央工业设施都是遮挡背景的主物件。远处可见暖浅地形和柔软深色树影，色彩与受暖光的主景相连。原游戏是否真的用贴图、景深或 3D，截图无法证明；本方案只规定要复现的可见关系。

开工时按参考重新画四类互斥像素标注：`F` 可见近中景、`W` 可见远水、`K` 对岸/远植被、`A` 天空/空气/更远树影；`X` 是 UI、角色、字幕及无法判断处。以 `U=F∪W∪K∪A` 为共同可观察区，`B_ref=W∪K∪A` 为参考背景。V20 旧 `P1_BACKGROUND_MASK.png` 只作描图起点。先在 50% 图上标大形，再以原尺寸检查水岸、树枝和 UI 邻接边；不要求手工逐像素描完整画幅，也不得未经边界复核就称旧遮罩为精确真值。这一步在看新候选之前完成，保存图、制作说明与 SHA。

### 先试取景，再决定是否改高台

用户提出让镜头更朝向平台、减少上方背景，是合理的构图方向；但“下压取景”和“降低相机高度”不是同一操作。**先保持相机位置与 53 mm 镜头不变，只试小幅下压取景**，这样可以把背景推出画面上沿并让近处平台占比增加。单纯降低相机高度会改变透视，可能露出更多远处，不作为第一步。

在 G1 先出三张 **960×539、无 DOF、同曝光、同物件** 的纯色取景图：C0=V20 基线；C1=相机朝下约 `1.5°`；C2=朝下约 `3°`。角度是试做值，先在 Blender 视图确认确实朝下，再记实际 Euler；不要为了过关直接改 53 mm、相机高度、平台高度或物件位置。选图时同时检查：上方灰色空洞是否明显缩小，P1 的左树、右草池、中央设备、台阶和栏杆仍有完整可读轮廓，中央蓝水仍有可见缺口；背景减少但水口消失、草冠被切掉或楼梯占满下半幅，都算失败。若 C1/C2 都过度裁切，回到 C0，改主景遮挡和 M03 内容。

**高台暂不整体加高。** V20 的前缘墙面与楼梯已占较大画幅，P1 的视觉重点仍是平台上的石板、设施和草池。整体抬高平台会连带改变楼梯、栏杆、设备承托、近岸高度与水位，并可能扩大前缘墙面。只有在选定机位后，叠图证明前缘高差仍比 P1 明显不足，才在单独灰模批次试 `+0.10–0.20 m` 的高差增量；必须让平台面、台阶、栏杆、设备、草池和 T01 接口作为一组重新连接，并重算水面高度。只加高墙体或只抬平台面均不允许。此增量是试做值，不是参考原作参数。

## 3. 场景结构：先让水岸成立

在新候选中复制可重开的 V20 场景作为比较起点；记录复制源 SHA、相机、画幅、色彩管理和当前对象状态。V20 报告相机为 `(0.25,-20.5,8.2)`、欧拉 `(1.23617494,0,0.01198983)`、53 mm、1920×1078、Standard、曝光 `-0.78`；V1 施工表的 V18 曝光 `-0.25` 与之不同。**以新候选实际 .blend 的读数建立 C0 基线，不混用曝光值。** 先按上节 C0/C1/C2 选定取景，重新投影 T01/水面/景片并生成候选遮罩，然后锁定相机和曝光；同一候选的后续色彩调整放在材质/绘画源。机位改变前后的图只用于选方案，不作为同机位画质改善证据；P1 参考遮罩保持已锁定值，候选遮罩按新机位重新生成。

### 3.1 T01 与旧对象

先从对象 ID 图和相机视线核对旧远地、远树、水、桥、B03/B04 与新 T01；逐对象记录 `keep / replace / split` 及原因。V20 的近岸记录在 `v20/preflight/B17_POND_COPING.json`：两段岸沿 `x[-6.2,-4.1]` 与 `[-1.5,2.2]`、`y[14.20,14.62]`、顶高 `z=.13`、暗壁底 `z=-.82`；中央缺口 `x[-4.1,-1.5]`。这些是**V20 实际几何起点**，不是 P1 原图参数，也不能只因坐标存在就判画面通过。

新灰模需同时显示：后廊/检修步道连接到主平台；岸沿有厚度、暗侧壁接地；水面在岸后且视觉上低于浅沿；中央水口的两端被自然遮挡，不形成“完整蓝椭圆”；没有干地拱桥。**V20 已证伪镜头朝向 M01 卡片的闭合水形，因此新候选默认先建水平或微曲面水面代理。** 起始范围仅供投影试做：`x[-5.0,2.5], y[14.4,17.5], z≈-0.18` m；水面高于旧暗壁底 `-.82`、低于岸沿顶 `.13`。水纹仍由可编辑 M01 贴图控制；世界坐标须在新候选用实际相机投影修正，不可照抄后直接做正式材质。对可见水口每隔约 `50–80` 最终像素取一个竖向剖面，记录由远到近的图层顺序与近岸接触点。若水口和岸线仍接不顺，先移动/拆分 T01、水面边及 M02；两轮无改善改远岸代理形状，不回到同一种竖立椭圆卡片。

## 4. 背景怎样画：从轮廓到材质

**正式源文件必须能逐层编辑。** 当前检查未在常见安装位置找到 Krita/GIMP/Inkscape；不要把它们写成已可用工具。默认可用路线是项目已有的 Blender Texture Paint/材质节点与单层图像源：分别保存 M01/M02/M03 的原始清晰图、遮罩和节点参数，打包到新候选 `.blend`，逐层导出 PNG；若实际安装并核验了 Krita，可改用 `.kra` 或 OpenRaster `.ora`。每层记录画布尺寸、alpha、UV/映射、修改日期和来源。程序脚本可以生成遮罩、低频噪声或预览色块，但 V20 的椭圆、短草条和大灰底不能充当正式美术。若执行环境无法实际编辑细节笔触，先记录工具缺口并配置可用绘画工具，不能用重复几何涂抹假装完成。用户已授权的小云雀只可作为局部草稿/远景片层来源，使用时登记模型、提示词、原始结果、整理源和最终映射；不以生成整图替代 Blender 最终渲染。

1. **先画 50% 构图色块**：在包含 F/T01 遮挡的同机位画布上，只用五个大色角色：暖浅石地、深暖树草、暗设备、蓝灰水、暖灰远岸/暗暖空气。看 50% 缩图时，蓝水必须是设施后的一段连续横向缺口；不能看见椭圆外轮廓或完整草条。
2. **M03 画 2–3 个不对称远树/空气大形**：深暖蓝灰上缘过渡到暖浅地平，保留树冠虚焦体积与大小不等的负空间。先画大、中形，最后才加低对比细节。避免等间距圆点、完整水平山脊、单色填满上缘。P1 可见区以外只做安全延展，不为不可见处制作精细内容。
3. **M02 画有方向的对岸**：以水后缘为主线，暖浅土色和暗草影成块变化；先用 3–5 个宽窄不同的大形打破条带，再添少量非均匀植被笔触。画面中不出现源图裁切的竖边；远岸比主石板更软、细节更少。
4. **M01 画水面而不画池形**：在水平代理的 UV 上从 P1 蓝灰 ROI `(125,145,154)` 的屏幕角色起步，在实际渲染中校正；横向做低频冷暖起伏、远岸弱倒影和少量柔边亮纹。近边由 T01 压住，远边由 M02 或远岸代理压住，不靠 alpha 圆形渐隐。水色与暖岸之间要有可辨接触线，不留灰色断层。
5. **在真实全图内合成**：每一层先保持清晰源，固定投影。无 DOF 图检查卡片边、白/黑 alpha 边、水岸高度和主景遮挡；通过后各导出一次受控柔化版。原 `σ2/4/6` 仅为 V1 试做数值，不是必须依次套用的目标。先对 M02/M03 局部试柔化，M01 保留水岸大形；正式图若远景仍硬，再做一次有记录的 DOF A/B，主体和岸缘必须清楚。

绘图尺寸按**最终可见投影**决定：可见轮廓每边留 `8–16` 最终像素遮挡余量，源图有效细节分辨率约为最终投影的 `1–1.5` 倍；为便于 UV 对齐，导出可保持 1920×1078 透明画布。不要在数百像素的可见背景里堆 4K 的叶/草细节。

### 色光校准口径

所有颜色都从**最终渲染的屏幕 sRGB**测，不把参考 JPG 的像素值直接填入材质。P1 标准给出的蓝灰远景中位数约 `(125,145,154)`、暖浅石地约 `(216,195,170)`、暗叶约 `(99,61,41)`，用于检验冷暖和明度角色。V20 报告的全图灰度 P50 131 与 P1 的 103 **不能单独证明亮度差**：P1 有 UI、人物遮挡，候选没有。新候选只在共同可观察区 U 和事先锁定的同类石地、草、叶、水 ROI 比较屏幕颜色，同时看 50% 灰度全图的暗部锚点。主景若偏亮，先处理树冠内层、设备暗腔和接触影，不能仅通过压全场曝光让背景灰幕变暗。背景应比主景降低边缘锐度与纹理对比，仍保留地形、树影和水岸的大形。

## 5. 验收要看最终图的背景，而非开关差分

G0 从 P1 人工复核 `U/F/W/K/A/X` 掩码并保存 SHA。G1 灰模用对象 ID + world 单独 ID。G2/G3 **以最终合成图的人工类别遮罩为面积计算输入**，对象/材质 ID 仅辅助定位，不假设普通 ID pass 能正确处理透明和景深。实施时先在 50% 正式图上按 F/W/K/A 大形描类别边界，再参考同机位、无 DOF 的纯色 ID 图辨认遮挡物；world 用醒目第五色单独标出。在原尺寸核查透明边、水岸接触处和景深边，再导出最终二值/类别 mask；逐类计算像素数和 SHA。若某像素是 world、M03 或远地，均属于背景；不因在景片 off 图里仍存在就漏计。附类别叠图让人能看出哪里是前景、远水、远岸和空气。成对渲染差分只用于技术排查光照或单个卡片贡献，**不能作为完整背景面积门禁**。

| 检查 | 通过要求 | 失败时先改什么 |
|---|---|---|
| 面积与位置 | 与复核后的 P1 `B_ref/U` 差值先按 `≤3` 个百分点检查；同时看 `W/K/A` 分布和轮廓叠图。面积相近但大灰幕或窗口位置错，仍失败 | 主景遮挡、M03/world 可见范围、水口与岸线投影 |
| 景片侧边 | 无 DOF 50% 全图及原尺寸接缝局部，不出现可追踪的竖直矩形边、白/黑 halo、漂浮草条 | 延长源图到遮挡后、重画不规则边、调整 T01/景片深度 |
| 水岸逻辑 | 至少在中央可见水口能指认：远岸 → 连续蓝水 → 真实近岸浅沿/暗壁；水低于岸，岸有承托，桥不压干地 | 先改 T01 与水平水面代理；不靠模糊掩盖 |
| 画风 | 远树呈有体积的柔焦不规则大形；暖浅岸、蓝灰水、暗暖空气与主景同色光；50% 图不出现“灰墙＋贴条＋蓝椭圆” | 重画 M01/M02/M03 的大形和色彩，不加采样或细草 |
| 主景清晰 | 设备、台阶、右草池轮廓清晰；背景比主景软；正式图和无 DOF 图均无几何接缝 | 修对焦/柔化组合，必要时只做一次 A/B |
| 交付 | `.blend` 可独立重开渲染；每张绘画源与透明导出一一对应，路径打包/相对化；图、源、报告同 SHA 绑定 | 修依赖与映射，不以原目录存在证明可移植 |

这些是**背景专项制作检查**，不改 P1 标准的六维权重、85 分及逐维 ≥3。面积 `≤3pp` 只有在 P1 遮罩重新复核且统计包括 world 后才可宣称通过；凡“看着像灰幕、悬浮椭圆、草带贴片”，直接记 `rework`，不让面积数字覆盖画面判断。

## 6. 最短施工路径与停止返工的条件

| 顺序 | 操作与只改变的主假设 | 最少证据 | 必须返工的反例 |
|---|---|---|---|

## 8. V2 复核结论与尚未关闭的条件

本方案的制作顺序和画面目标已一致：先锁参考、清理容量与核工具，再用水平水面和近岸灰模证明连续关系，之后画可编辑远景，最后从正式图统计完整背景并按 P1 六维评分。它**可以作为新候选的施工入口**，不等于新背景已能达到 85 分。

开工前仍须关闭两项实际条件：项目已约 15.085 GiB，需按工作流完成安全容量预检；绘画工具要在执行机上核验，若只有 Blender，则使用其 Texture Paint/节点源并先做一张可编辑的局部样张。G0 重描后的 P1 背景遮罩与 G1 水岸投影也都属于待实测结果，不得把 V2 的世界坐标、颜色样本或面积容差当作已通过证明。正式图出现灰幕、闭合椭圆或草带侧边时，即使报告和面积数字齐全也要返工。
