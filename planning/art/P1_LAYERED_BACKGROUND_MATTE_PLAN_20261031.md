## 0. P1 实图里，主景怎样接到远景

以下只描述截图中**可见的画面关系**。一张截图不能证明原游戏实际用了平面贴图、景深后处理或完整 3D；本方案的景片是为复现可见效果而选择的制作方法。

| P1 可见区域 | 主景/远景衔接方式 | 对本项目的施工含义 |
|---|---|---|
| 上中部蓝灰水色，约 `u=.30–.54,v=.13–.27` | 水面不是从主石板边缘直接开始；它位于一段较低的灰色弧形边/池沿之后，前方还有浅色后侧平台与栏杆、设备交错遮挡 | M01 远水景片放在 T01 真实后侧平台/岸沿之后；至少保留一段可见的近沿与暗下缘，不能让蓝色贴图直接贴住石板的硬切口 |
| 中央偏后的平台与栏杆，约 `u=.24–.53,v=.24–.42` | 浅色平台面、栏杆和深色设备在水色前方相互叠压；这是从清晰主景过渡到模糊远景的**缓冲层** | T01 的检修步道、短栏杆和设备背部要先成立，再放景片；交界线应多次被结构打断，不能用一整条水平岸线切开画面 |
| 左侧树冠/树下植被与右侧高草圆筒 | 两侧主景形体伸进画面上部，裁掉水和远地的左右端；远景只在中间及少量局部间隙出现 | M01–M03 可以在世界里比露出部分宽，但最终左右边必须藏在 F02 主体后；不要画完整池形后让它全部露出来 |
| 蓝水后方暖浅地与远树 | 颜色仍属于同一秋日暖光环境，但细节明显降低、轮廓变软；近处栏杆和草筒边缘更明确 | M02/M03 用大形、低对比和预留柔化；保留暖冷关联，不用突兀的摄影风景或与前景不同的光向 |

因此 P1 的视觉顺序是 `清楚的石板/设施 → 略退后的平台与栏杆 → 可见池沿/暗下缘 → 柔和的局部蓝水 → 更软的对岸与远树`。**贴图接缝藏在“平台—栏杆—池沿—树草”组成的 3D 缓冲层后面**，而不是靠把贴图边缘涂成透明渐变来单独解决。画面上也没有足够证据要求完整自然河流；局部水景/浅池的可见轮廓比“必须有一条长河”更贴近参考。V18 的拱桥仍须撤除，因为参考的层次并不需要一个旱地拱桥。

## 1. 最终画面长什么样

观众先看到清晰的前景台阶和栏杆、统一的浅暖石板；视线进入中央设备、左树和右侧草池组成的作业庭院；后侧由检修步道、栏杆、浅岸沿和暗岸壁形成**主景的结束边**。仅从左树、中间设施、右草池之间露出一小段柔和蓝灰水色和极少量对岸树地。远景不出现完整池形、横贯全宽的裸坡或清晰的独立大物件。

前景/中景的使用逻辑、承托、投影和遮挡仍靠真实 3D。**远水、远岸、远树使用原创分层绘制贴图**，作为镜头内的景片。近岸必须保留真实厚度、接触影和水面低于岸缘的视觉关系。左侧干地拱桥撤掉，改为与现有通道相接的低调检修步道及栏杆；若今后决定保留“桥”，须另立水道穿桥方案，不沿用本方案的旧桥。

### 画面分区，先当试做范围

归一化屏幕坐标从左上 `(0,0)` 到右下 `(1,1)`。下表是**执行时的初始框**，不是 P1 自动分割结果；开工 G0 先手工描 P1 可观察背景遮罩，将实测比例写入候选 profile，再锁最终占比。UI、文字和人物遮住的参考区域不推测隐藏地形。

| 层 | 屏幕位置与作用 | 清晰度 |
|---|---|---|
| 前景台阶、近石板、栏杆 | 主要在 `v≈.55–1.00`；作为画面近处边框 | 台阶边、栏杆连接、石板接缝可辨 |
| 中景作业庭院、左树、右圆筒草池 | 主体约 `v≈.20–.68`；左右树草可继续伸到画面上缘，覆盖远景 | 中央设备、草池、树干/主枝清晰；这里是正式焦点 |
| 3D/贴图交界 | 大致在中景设施之后，由不连续的栏杆、步道、岸沿、树草轮廓组成，**不是一条水平切线** | 近岸有厚度和阴影；遮挡关系可读 |
| 可见背景景片 | 远水主要保持在 P1 锚区 `u≈.30–.54,v≈.13–.27`；远岸和树地只从局部缺口露出 | 只需保留水色、岸线和树地的大轮廓；细枝/细石纹明显软化 |

前景＋中景可读主体的画面覆盖先以约 **75–85%** 为灰模范围；无遮挡远景先以 **15–25%** 为试做范围。**这不是已经从 P1 测得的硬阈值。** G0 的统一测量口径如下：在 P1 上先锁定可观察区域 `U`（排除 UI、文字、人物及不确定遮挡），再标出其中确实可见的远水、远岸、远树/远天空 `B_ref`；候选用**同一个 U** 标注 `B_candidate`，比较 `|B∩U|/|U|`，同时另报候选全画幅的背景比例，防止只在遮挡区外偷放大背景。参考遮罩和定义先保存 SHA，再看候选；不要因候选结果改口径。若 P1 实测比例落在 15–25% 之外，以**实测参考**和可见轮廓为准，并记录修订理由。这里的“面积”只计最终图中露出的像素，不计被树、草池和设施遮住的贴图或素材原文件面积。

## 2. 3D 与贴图各负责什么

| 资产组 | 方法 | 必须看见 | 禁止 |
|---|---|---|---|
| F01 前景平台/台阶/栏杆 | 保留并修正 V18 原生 3D | 支撑、高差、投影、入口和石材细节 | 用贴图替代承重边和可见阶面 |
| F02 中央设施、左主树、右草池 | 原生 3D 与可编辑植物母版 | 设备组关系、树干枝叶、草根在土内 | 为挡背景随意堆新道具或把主景也做糊 |
| T01 主景收口 | 低复杂度真实 3D：后侧检修步道、短栏杆、近岸浅沿和暗侧壁；局部实土/植被 | 平台走到哪里、岸从哪里开始、水为什么低于岸沿 | 旱地拱桥、横贯画幅的整齐挡墙、无厚度岸线 |
| M01 远水 | 一张局部透明绘制层，位于 T01 后方；可用受控平面贴图或浅水代理面。只画镜头需见到的局部水面，近沿的结构由 T01 承担 | 低饱和蓝灰水色，边界被近岸及左右主体遮住；在固定镜头里看起来低于岸沿 | 完整椭圆/尖叶蓝板、清楚高频波纹、镜面大反光，或把竖直景片的实际厚度误称为真实可行走水面 |
| M02 对岸暖地 | 独立绘制层，深度在 M01 之后 | 少量暖灰土色、非规则低起伏和树影大形 | 横贯全宽的米黄色带、可数的重复小树 |
| M03 最远树地/空气层 | 独立绘制层，深度最远，可含柔和天空色 | 只从主景间隙露出的模糊冠形和暖冷过渡 | 大建筑、亮天空整块铺满上缘、锐利山墙 |

至少分成 M01/M02/M03 三层，便于分别调可见面积、轮廓、色温和虚化。若 P1 遮罩表明 M02/M03 在镜头中几乎不可见，可以合并两层，但不许把远水、岸、树全部烘成一张不可修改的最终图。每层保留可编辑的绘画源（例如分层 `.kra`/`.ora` 或 Blender 原生绘画源）和单独的透明导出文件，记录源与导出的对应关系；渲染用相对路径或打包纹理，在**复制到另一临时目录后重开 `.blend`** 验证不丢图。最终画面必须由该 `.blend` 重新渲染。

## 3. 绘制和 Blender 落位

### 3.1 先画轮廓，再画纹理

1. 在 `1920×1078` 同画幅参考拷贝上标注：可观察远水、远岸、远树的露出区域；遮住未知区域；记录参考每层**可见像素面积**和目标轮廓。
2. 出一张低分辨率色块草图：暖浅主景、深暖树草、暗金属、蓝灰水、低对比远岸。草图须同时显示 T01 的岸沿和 F02 的遮挡，不单独画一张漂亮风景。
3. 分层绘制 M01/M02/M03 的**原始清晰版**；沿轮廓加少量大形变化，不画前景级砖纹或叶脉。先按固定镜头实际投影像素决定绘制尺寸，起始为投影宽高约 1–1.5 倍，不因为原始图可以很大就做远景级 4K 细节。各层边缘保留透明像素和足够的颜色延展，防止渲染时出现白边/黑边。
4. G1 色块/遮挡通过后、G2 景深 A/B **之前**，从原始清晰版各导出一份固定柔化版：按数值施工表先试 M01/M02/M03 的 Gaussian σ=2/4/6 最终输出像素。A/B 只改变光圈，使用**相同**的柔化素材和焦点。记录原始清晰文件、柔化文件、方法和参数；不能以重复缩放 JPEG 获得模糊。水面和岸的主体边界仍要可辨，远树细枝/远地细纹可更软。

素材优先用 Blender Texture Paint、Krita 或其他可编辑绘画源；如使用已授权的小云雀，仅生成远景草稿或局部分层素材，再人工整理成原创 M 层。登记模型、提示词、原始结果、裁切/改画、映射和来源。**不直接把 P1 截图抠成最终背景，也不让 AI 生成整张最终场景。**

### 3.2 景片放置与材质

固定相机继承核验后的 V18 机位（53 mm、1920×1078、Standard；若 G1 有充分证据改机位，须重建整个对照基线）。先以相机视线方向建立三张平面或曲面景片，顺序为 `F01/F02/T01 → M01 → M02 → M03`。用相机投影把每层的四角和关键轮廓对齐屏幕目标，记录世界坐标、对象 ID、屏幕包围框；不能只凭代表点或旧 B05/B06 世界坐标摆放。景片之间留足深度避免 Z-fighting，近岸在所有景片前方。

景片使用不受主光直接强烈影响的稳定材质（例如受控 Emission/环境混合），但要在正式 `Standard`/曝光下校准最终屏幕颜色。按对象逐项关闭不需要的阴影、反射和其他射线贡献，**保留相机可见性及正确的前后遮挡**；不能把所有射线一关导致透明层消失或穿帮。透明水色层只在需要的形状内有 alpha，其他区域应能露出 M02/M03；每层检查 alpha 模式、透明排序与抗锯齿。边缘伸入主体遮挡后约 **8–16 个最终输出像素**作为试做余量，近景结构遮住接缝；此数值是防漏缝初值，不可因此让景片盖住栏杆或草根。

由于 M01–M03 是不同深度的景片，不能假设“任意摆一张相机平行平面”就会得到正确池形。先在固定机位上对准可见近沿、远水轮廓和对岸的屏幕位置，再用侧视检查水色景片确实在 T01 后、M02 前，且没有穿过步道或主景。**接缝诊断用原始清晰景片并关闭 DOF；正式图才用受控柔化景片及选定景深。两张都必须通过。**只在正式模糊图中看不出接缝不算通过。

固定机位允许景片只为这个镜头设计。正交/侧视诊断中景片可能显得薄，这不是交付错误；但它们不得进入可见步行面、穿过近岸、向主平台投出假阴影。项目以后若加入自由移动相机，须重新制作视差层或远景 3D，此单镜头贴图不能直接充当全游戏地图。

### 3.3 景深：背景软，主体清楚

先完成几何遮挡、可见背景面积和色块，再做最多两档**同机位、同光照、同曝光、同焦点、同柔化景片**的光圈对照。按数值施工表先用焦点 `22.5 m`、A=`f/1.2`、B=`f/0.8`；这是 V18 焦点的试做继承，**不是 P1 原作参数或保证合焦的值**。如果两张的中央设备都不清楚，只用相机空间测得的设备中位深度做一次有记录的焦点修正，不扫描一串焦点。前景台阶、右侧主草池仍须读清轮廓。M01 水面保留大形边界，M02/M03 的细节逐级更软。若两张都因双重虚化失败，改用原始清晰景片和较弱 DOF 做一次技术路线替代，不继续提高模糊。V18 的 `f/0.55、22.5 m` 是历史记录，不是目标值。

景深仅负责**最后一级清晰度差**。如果关闭 DOF 的灰模仍是“大片远地”和“孤立蓝池”，应返回改 T01 遮挡及 M 层面积，而不是继续试光圈。

## 4. 执行顺序与最小试图

| 阶段 | 一次只判断什么 | 输出 | 退回条件 |
|---|---|---|---|
| G0 参考锁定 | 主体/背景可见遮罩和水色锚点；锁定共同的可观察区 U 与遮罩口径 | `P1` 标注图、U/B_ref 面积、遮罩源与 SHA、不可观察区域说明 | 参考未锁、把 UI 遮挡区猜成远景、看过候选后改口径 |
| G1 空间灰模 | 撤桥改步道、T01 近岸厚度、三层景片的可见面积和遮挡顺序 | 960×539 灰模、对象 ID/深度图、侧视剖面、世界/屏幕坐标 | 桥下干地、主景/背景无分界、远景超面积、卡片穿主景或岸悬空 |
| G1 色块 | 主景主导，水只是局部冷色缺口 | 960×539 同机位彩色与灰度图 | 一条远地横带、蓝水完整椭圆、远处比主体抢眼 |
| G2 景深 A/B | 主体清楚、M02/M03 柔化 | 两档参数与同机位对照；保留无 DOF 结构诊断 | 主景模糊、远处仍与主景一样锐、双重虚化使岸线消失 |
| G2 同框素材 | 树、草、石、金属和景片在同一图内统一 | 组合图和必要局部 | 贴图像独立海报、alpha 白边、色温与主景断裂 |
| G3 最终图 | 原生源复现、场景语义、85 分标准和证据绑定 | `.blend`、分层源/导出图、最终渲染、对照遮罩、复制目录重开复现、`REVIEW.md`、交付/门禁记录 | 任一 P0 语义错误或正式视觉标准未达即返修；机械通过不代表画面通过 |

只有 G1 灰模与色块通过后才为远景做正式绘制，防止先画精美大背景，再发现镜头里其实只需要一小块。每次失败记录一条具体原因与改动前后证据；同一办法两次无改善就换结构或遮挡方案，不盲目扫焦距、光圈和贴图模糊半径。

## 5. 交付与验收硬条件

- **背景占比：**同时展示 P1 标注遮罩、候选可见遮罩及共同 U 上的面积比；初版约 15–25% 是试做范围，正式目标以 P1 实测锁定。候选另报全画幅背景占比。背景不横贯全画幅，也不靠裁图藏掉主要锚点。
- **分界：**在 50% 全图上能指出主景的后侧栏杆/岸壁与其后的水和远树；分界不应是一条无厚度、完美水平的贴图边。
- **清晰度：**中央设施、台阶、右侧主草池可读；远树细枝和远地细纹明显更软；水和岸的大形仍可读。提供正式图和无 DOF 诊断图，证明虚化没有掩盖几何错误。
- **场景逻辑：**不保留干地拱桥；近岸、水色、远岸连续，设备和平台有合理通道；草根、栏杆和岸壁有承托。
- **融合：**无 DOF 清晰诊断和正式图都看不到景片白/黑边、漂浮边、重复纹理、异常投影或反射；远景冷暖/明度与主景属于同一光色系统。若清晰诊断暴露接缝，必须改 3D 遮挡/景片定位，不能只靠加模糊遮住。
- **可编辑与来源：**Blender 中每层可单独换图/调位置；保留分层绘画源、导出图、映射、来源、相机/景深参数、命令/耗时/SHA。复制候选到另一临时目录后重开源并复现，检查外链。旧 V18 候选和绑定文件不覆盖。

### 质量门禁的真实能力边界

现有项目级 Stop hook 只能校验 SHA、分数算术、状态与评审字段，**不能从 JSON 自动看出景片接缝、主景失焦或水岸空间不通**。下一版在现有评分体系内把这些可见问题明确写入 `cool_soft_background`、`functional_midground_structure`、构图与空间、光照纵深的逐项证据；出现本方案第 5 节反例时，对应项记录 `rework`/`fail` 并返修。制作侧须亲自查看绑定正式图和无 DOF 诊断图；两份独立盲评也须查看同一张正式图，不能只接收制作侧的自评 JSON。这个人工视觉环节是方案必要条件，不能宣称现有 hook 已自动保证背景画质。

此方案只替换**远景制作方法**，不改变 P1 固定参考、现行 85 分/逐维门槛及 G0–G3 质量闭环。`P1_BACKGROUND_PLACEMENT_START_V1.json` 的 V18 几何和桥位置不能作为这套景片方案的施工表；新候选应从本方案的屏幕遮罩和投影记录生成自己的坐标表。

## 6. 方案复核：目前合理之处与尚待试图证明的风险

本方案在**固定机位单张静态图**的范围内逻辑成立：主体与承重边保留 3D，背景在遮挡后用景片承接，能以较低成本控制面积、颜色与柔化程度；桥水关系通过撤桥改步道消除。它尚不是“已经证明达到 P1”的结果，以下问题必须用新候选证据关掉：

| 剩余风险 | 已有控制 | 开工后的关闭证据 |
|---|---|---|
| P1 背景面积尚未真实测量，15–25% 可能偏离参考 | G0 先锁 U/B_ref，优先用实测而非估值 | 带 SHA 的参考遮罩、候选遮罩及两种面积比；人工复查边界 |
| 平面水色可能像竖立背景板，与近岸脱节 | T01 真实岸沿/暗壁遮挡，M01 投影按固定机位对准 | 无 DOF 图、正式图、侧视和对象深度图同时证明近岸在前、水色在后且没有穿插/漏缝 |
| 预绘柔化叠加相机 DOF 可能使水岸消失、主体失焦 | 保留清晰版；只做两档同设置 A/B | 中央设备、右草池、台阶和水岸局部对照，记录焦点/光圈/所用素材版本 |
| Emission/透明层可能与实物光色断裂或出现 alpha 边 | 正式色彩管理下校色；检查射线、排序和边缘延展 | 亮石背景与暗树背景下的局部拼接图，最终图无白边/黑边、假阴影和异常反射 |
| 当前 Stop hook 无法自动识别视觉失败 | 在现有构图/结构/远景检查中记录可见反例，人工看绑定图 | REVIEW 与两份独立审阅对同一最终 SHA 的逐项可见证据；不能只给 gate JSON |

其中前三项是**G1/G2 阶段的真实制作试验**，目前没有结果。若无 DOF 灰模无法把景片与主景接顺，应先调整 T01 遮挡和景片投影；仍失败时改成少量低复杂度远景 3D/曲面代理，不应通过增强模糊或改评分掩盖错误。该回退只影响远景制作技术，不改 P1 参考和主体构图目标。

**一次连续执行的止损规则：**每个假设最多两次同方法试图。第 1 次改一个主因并出 960 图；第 2 次只验证同一主因的有依据修正。仍失败就切换到方案 §6 的替代方法，而不是继续扫描坐标、模糊半径或光圈。可按 `面积/遮挡 → 贴图接缝 → 主景合焦 → 光色 → 细节` 顺序返修；前一层失败不进入后一层。**“两次”只限制重复方法，不是未达 85 分就停止任务的许可。**

**最终交付判定：**数值预检只用于阻止显见错误，最终仍按 P1 的六维 85 分、逐维 ≥3、四项组合与现有硬门槛看图审阅。桥下干地、完整蓝池、主体/远景贴图硬接缝、前景或中央设备失焦，任一可见时，即使数值面积和自动 gate 通过，也必须返修。V18 源、正式图和绑定证据保持原样。
