# 美术返修方案 · 达标版（2026-10-27）

## 0. 结论前置

上一轮三档对比暴露了一个**共因缺陷**，它不是风格差异，是三档都有的错误：

> `tex_stone_tiles.png` 是一张 4×4、带亮灰浆线的石材图集。把它平铺到每块石板上，
> 亮浆线被 mip 过滤后表现为**满屏白色虚线点阵**，同时让「砖块尺寸」看起来比几何缝小 5 倍。
> 这就是「地板格式不统一」「砖面上有白线」「砖块看着混乱」三条问题的同一个根因。

实测证据（同一区域放大 6 倍）：O 与 R 两档都出现完全相同的白色虚线点阵，
间距约 0.16 m，与几何缝（约 0.9 m）不同步 —— 所以不是倒角、不是裂纹、不是阴影。

## 2. 逐条修复项

### P1 铺地贴图（新）—— 去掉亮浆线格
- 新增程序化无缝石材噪声 `tex_stone_noise.png`（512²，只有斑驳与颗粒，无格线）
- stone_base / light / dark / mortar 四个材质改用它
- 预期：铺地 edgeDensity 35 → ~17

### P2 铺地格式统一
- 三种铺法（plaza/path/edge）合并为一种「大板」语言：每 4 m 模块 3 皮、每皮 2–3 块（≈1.33 m）
- `N5_PAVING_UNIFY` 默认改为 1
- `corner_jitter` 归零 → 缝宽恒定，侧壁垂直
- 预期：砖块尺寸全场景一致，退化为参考图的「大块浅色石板」

### P3 砖缝
- 砂浆面从砖面下 100 mm 抬到 **4 mm**，材质压暗
- 缝表现为 4 mm 深的暗槽而不是一片亮面
- 预期：jointContrast 41 → ≤30

### P4 砖面不长草
- 撒草时用「草团半径 + 0.1 m」做整圆碰撞，已实现；本轮把 margin 从 +0.10 提到 +0.16
- 顺带校验 VEG_AUDIT 里 on_paving 数量必须为 0

### P5 草（形态 + 颜色）
- 叶片加宽：`grass_width` 1.9 → 2.6；高度 1.1 → 0.92
- 叶数下调：`grass_count_scale` 0.72 → 0.46（少而宽 → 边缘密度降一半）
- 覆盖补满：花坛/路边 turf 密度 ×1.25，消除空地
- 颜色：`grass_dry` #CC9466 → #BE8E4E，`grass_pale` #E0B583 → #D3A868
- 预期：edgeDensity 31 → ~17，sat 31 → ~43，lum 135 → ~112

### P6 树叶（浅色 + 降饱和）
- `leaf_ochre` #B5885F → #C9A46E，`leaf_gold` #D8C4A4 → #E6D2AE
- `leaf_amber` #A87B55 → #B98F63，`leaf_mass` #6B5540 → #7A6650
- 叶卡尺寸 `leaf_scale` 2.0 → 2.4（更大更整，减少碎边）
- 预期：tree sat 54 → ~38，lum 75 → ~93

### P7 C 档树冠（不像树 + 团块掉地）
- 7 个偏移团块 → 11 个按半球壳排布的团块（半径 0.85–1.10，相互重叠 ≥35%）
- 整体压扁 flatten 0.86 → 0.72，形成横向宽冠
- 团块团块最低点必须高于树干分叉高度，禁止落地
- 灌木团块撒点同样走 on_paving 整圆判定

### P8 R 档过曝（草变白刺）
- `styleColor('r')` 的 `l0*1.10+0.02` 改为 `l0*1.0+0.01`（写实不该整体提亮）
- 雾起点 40 → 55，雾色 (230,206,178) → (232,214,190)
- 预期：草地 lum 回落，远处不再糊成白色

### P9 光照
- key/ambient 比例保持（阴影对比需要），只改雾与天光色
- O 档环境光 13200 → 11800，key 188000 → 196000（加强主光、压环境 → 更接近参考的硬光）

## 3. 执行顺序

1. 生成 tex_stone_noise 并接上 → 单独出一次 O 档验证格线消失（最快能证伪的一步）
2. P2/P3/P4 铺地三项一起给几何
3. P5/P6 草叶参数与配色
4. P7/P8 分档修复
5. 三档整跑 + 指标复测 + 拼版

## 4. 风险

- 抬砂浆面会让缝变浅，若 jointContrast 掉到 20 以下（缝看不见）则回调到 6 mm。
- 草加宽后三角面略增，但 blade 数下降更多，总体应持平或下降。
- 大板从 8 皮降到 3 皮，石板三角面减半，铺地开销反而降低。
