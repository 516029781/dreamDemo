## 3. 每一步的具体改动（落到函数级）

### M1 总裁盒（`build_ceo()`）

| 动作 | 代码位置 | 参数 |
|---|---|---|
| 删玻璃顶 | `add_box("ceo_roof_glass", ...)` 整行删 | — |
| 女儿墙 | 新增四周 `add_box`，高 0.6，厚 0.3 | 顶标高 = 盒底 + 4.5 |
| 黄铜压顶 | 女儿墙顶 0.2 m 一圈 | 材质 `brass`，宽 0.2 → 1.4 px |
| 檐口 | 女儿墙外挑 0.8 | 盒内形成 0.3–0.5 m 暗边 |
| 自发光 | `"caramel": ... "#E8D6B4", 0.35` → **0.07** | 防开顶过曝 |
| 删假 AO 环 | `ceo_ao_*` 四块删 | 改靠真实投影（14–17 m 偏移） |

### M2 换色 + 明度分工（`make_mat` 调用处）

**先换色，再谈明度**——v05 四室是灰绿（S 0.03–0.07），实机是青/蓝/墨绿（S 0.16–0.64），色相没换对，明度怎么调都像"灰模型"。

| 材质 | v05 现值 | 改为 | 依据（实机） |
|---|---|---|---|
| `h1` 离心 | `#77837E` | **`#547684`** | `#1E2A2F`（L0.15 S0.22）提亮 |
| `h2` 浮力 | `#8A8F86` | **`#477A8A`** | `#16262B`（S0.32 深青） |
| `h3` 蓝室 | `#A2A396` | **`#3A6DBF`** | `#122640`/`#32568A`（藏蓝） |
| `h4` 黑室 | `#6E7568` | **`#58837D`** | `#21312F`（墨绿青） |
| `wall_h4` 绿板 | `#3F7F58` 整面 | **`#4A7A5A`，只留 3–4 块** | 实机绿仅占强调色 10% |
| `caramel` 总裁 | `#D8C9AE` 奶油 | **`#95755B` 木地** + `#B0947E` 墙顶 | `#4B3B2E`/`#8E7863` |
| `dock` 坞底 | `#878D8C` | **`#788980`** | `#47514C` |
| `garden` 花园 | `#B5A88F` | ×0.88（保持） | 实机无对应，按明度层级给 |
| 设备/家具 | 各色 | ×0.85 | 暗部主力 |
| 阴影 | 乘 0.55 灰 | 乘 `#5A6470` | b* −6 |

**换色必须"保形"**：着色器里改 HSV 的 H/S，L 只做整体缩放，**不许整间平涂**——模拟显示整间刷色 S1 掉到 40.3%（不达标），保形换色 48.7%（达标）。

**新增配套**：蓝室肋间灯带由暖白改**蓝**；总裁加 6–8 株沿墙绿植；撤离点地面铺蓝色环境光（`#467CCD`），黄框保留。

### M3 环境（`build_scene` 主流程 / `build_camera_light`）

- 水面：`add_box("water", -20, 260, ...)` → **`-900, 1100, -1100, 1000`**
- 世界：地平 `#8FA6AE` → 天顶 `#D8DDD4`，强度 0.82
- 雾：`render_v6_views.py` 里**仅 hero** 给 world 加 `Volume Scatter`（density 0.0008, color `#42566A`），渲完删掉
- 山脊：三层重放到 `y=+240/+300/+360`，机位可见

### M4 结构层次（新增 `build_roof_structure()`）

```
每室 6 道桁架：跨短边，间距 6 m，截面 0.5×0.4，顶 = 墙顶 − 0.4
黑室 2 道行车梁（1.2×0.6，距地 8 m）＋ 蓝室 1 道
每室 4 组吊灯：Ø0.5 灯罩 + 0.06 吊索，距地 6.5 m
```

### M5 插画 shader（`apply_material_upgrade()` 后追加 `apply_illustration()`）

| 步骤 | 节点 | 参数 |
|---|---|---|
| 压 V | `SeparateColor(HSV) → ColorRamp(Constant) → CombineColor(HSV)` | 断点 0.34/0.62，V 三档 0.42/0.66/0.86 |
| 回填渐变 | `MixRGB(Soft Light)`，原色为 Color2 | Fac 0.40 |
| 阴影换色 | `MixRGB(Multiply)` `#5A6470` | 0.55 |
| 反射暖光 | 叠 `#8A6E52` | 0.08 |
| 露白 | `AmbientOcclusion(0.4) → 反相 → ColorRamp → 混 #E6E0D2` | 0.25 |
| 方向笔触 | `Noise` 经 `Vector Rotate 45°`，Scale (7, 1.2) → 混入 roughness | 强度 0.12 |

只对 **6 类**开：`platform / garden / dock / wall / metal / wood`（其余保持原样，避免全图糊）。

### M6 2D 层（`v6_post.py` 新增 `overlay_pass()`）

| 元素 | 做法 | 参数 |
|---|---|---|
| 边缘抖动 | 提取亮度边缘 → 噪声阈值 → 沿法线 ±1–2 px 位移（numpy `roll`，2× 图执行） | 只对混凝土/涂装区 |
| 手绘标注 | PIL 画线，端点随机 ±1.5 px；箭头双线 | D1–D6，共 10 处 |
| 字体 | 数字/字母自绘路径；中文用思源黑体子集 | 许可证记入 MANIFEST |
| 纸纹 | 2048² 低频噪声 | 混合 6% |
| 颗粒 | 高斯 | σ 1.8/255 |
| 暗角 | 径向 | 0.12 |
| 四边渐隐 | 线性 | 24 px |

### M7–M9

- 渲染：`render_v6_views.py`，主图 **32 spp**（抖动噪声需要），核心区 32，英雄图 48 + DOF
- 后处理：master 上合成 overlay → 缩 1680×2478 → 加 70 px 出血
- 门禁：`space_base_check_v4.py` 读 r03，**24 条**；S11–S14 首次 `diagnostic_only`

## 5. 每步的验收阈值（写死，不靠感觉）

| 步 | 指标 | 通过 | 不通过怎么办 |
|---|---|---|---|
| M1 | 盒内 mean / std | ≤0.88 / **≥0.15** | 降自发光、加深檐口 |
| M2 | 模拟 S1 | **≥50%** | 回调花园/坞底系数 |
| M3 | hero 水面跳变 | **≤8/255** | 加雾、扩水面 |
| M4 | 每室投影条纹 | **≥6 道** | 加桁架密度 |
| M5 | 三峰 / b* | 3 峰、**−6±2** | 调断点与 V 值 |

| M6 | 抖动振幅 / 颗粒 | 1–2 px / σ1.8 | 调阈值 |
| M8 | G1/G4/G6/G7/W1 | 全过 | 修后重渲 |

## 6. 已知风险与回退（一次性执行特有）

| 风险 | 触发 | 回退 |
|---|---|---|
| **渲染时间翻倍** | 32 spp + AO 节点 | 迭代用 16 spp 小样；正式图再 32 |
| **AO 砂眼** | 露白节点噪 | AO 距离降到 0.3、强度 0.2，或改 2D 加亮边 |
| **压档发灰** | Soft Light 比例错 | `illustration_strength` 0.4–0.6 之间调 |
| **overlay 错位** | 坐标没对齐 master | overlay 用世界坐标生成，assert 四角锚点 |
| **字体授权** | 微软雅黑不可随包 | 自绘数字/字母；中文用 OFL 字体子集 |
| **S1 跌破** | 大面积压暗 | 先跑 §3 的模拟表，再改色（有脚本） |
