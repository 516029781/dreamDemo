```
北 ┌──────────────┐  核心区 2×2（十字过道）
   │  H1  │  H2  │
   │──────┼──────│
   │  H3  │  H4  │
   ├──────────────┤  大路面（内含 34×34 花园）
   │    ▣ 花园    │
   ├────────────┤    泊车 / 堆场
   │            │
   ├──────┬─────┤    桥
   │  码头  │
   └──────┘
```
