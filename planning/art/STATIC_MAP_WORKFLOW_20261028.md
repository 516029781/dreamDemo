# P1 静态地图制作工作单

状态：**当前执行范围**。更新：2026-10-28。用户现在只要求绘制一张可展示的静态地图场景画面。本文覆盖本阶段的制作顺序、交付和验收；`PROJECT_TASKS.json`、`ACTIVE_REWORK_CYCLE.json`、`tools/workflow.py summary --write` 仍记录完整游戏的历史/暂停任务，不用于领取本阶段工作。恢复游戏制作须由用户明确提出。本文件不修改旧合同、分数或已冻结证据。

## 目标与边界

制作**一张完整构图的 P1 风格秋日庭院地图静帧**：在固定相机内同时看见有厚度的石板平台、前景台阶和栏杆、可辨识的设施、自然分枝的秋树、成片枯草和冷暖分明的远景。画面要像一个可信的场所，而非盒子、尖片和同色平面的拼接。布局和资产是本项目原创；学习 P1 的空间、材质、植被和光色规律，不逐像素复制。

本阶段**不制作也不验收**：角色与骨骼、行走/交互、任务、UI、Cocos/GLB 导入、微信小游戏、真机性能、全路线 Q 检查、47 组资产、四卡 ENV/CHAR/UI/MIX 或 I07 完整候选。现有可玩 n5 只作失败基线；不要改它的冻结源、构建、截图、manifest 和哈希证据。静帧不宣称可玩、可发布或可在微信运行。

主参考固定为 `reference/_raw_screenshots/P1/t084s.jpg`，SHA256 `13706e7eab96726565156a9e6440727de5d5bac82ee9c09c293a5745dd7446de`。只比较其中的**环境画面**，角色、文字、按钮和视频压缩字幕在取样和评分时排除；其他 P1 帧只作局部辅助观察，不能取代主参考。基线图为 `delivery/next_cycle/n5/T6/candidate_n5s1q/captures/formal_no_ui.png`，只读。

| `reference_analysis/`、`renders/01b_color_key.png` | 六锚点标注、石板接缝/树冠负形/草池形状设计图，以及灰模后立即制作的整画面色块和初步灯光图 |
| `METHOD_PROOF.md` | `02_material.png` 必须是含地板、树、圆筒草池、设施及初步最终光色的同镜头组合试图；地板、树、草、整体光色分别记录 `pass|rework`、对照图与换方法决定；四项未全过不做常规扩批，止损后按下文诚实交付完整静帧 |

| `REVIEW.md` | P1/基线/本版同尺寸对照、逐项评分、失败反例、返修决定；最终版附命令、退出码、耗时、输入与输出 SHA |

源贴图可采用 Blender 可编辑节点、UV、程序化生成或手绘分层文件。**静帧不要求先烘焙引擎贴图或导 GLB**；若以后进入游戏阶段，再单独验证导出材质。项目规则仍禁止 AI Image、扩散/图生图作为本地图素材或概念图。使用 Blender 5.2.3 LTS；入口支持 `P1_BLENDER_EXE` 覆盖。不要用旧 4.5 路径执行新工作。

当前画面问题、对应解决方案与目标，以及美术 skill、插件和素材的选型，统一见 `planning/art/STATIC_MAP_ART_SKILLS_AND_TOOLS_20261028.md`。t084 的可观察特征、六个构图锚点、色彩样本和 90 分量表见 `planning/art/P1_T084_ART_DIRECTION_STANDARD_20261028.md`，由 `.agents/skills/p1-art-director/SKILL.md` 指导看图判断。本工作单负责 S0–S5 的执行与交付。未试用的工具不得写成已安装。

## 按顺序制作，低质继续返修

执行时优先按选型文档的 **A–E 推荐路线与“扩批前的组合画面关”**推进：A 参考锁定对应 S0，B 整画面灰模与早期色块对应 S1，C 四件同机位试件及组合试图对应 S2/S3，D 扩成完整静帧对应 S4，E 反例返修贯穿 S0–S5。P1 相机参数未知，灰模时先匹配屏幕锚点，确认布局后才锁新相机；旧 n5 游戏相机不能强制继承。必须先让整画面构图和色彩分工过关，再批量制作物件；局部物件合格不能代替组合画面关。

下表是本阶段的完整任务清单。执行模型在 `REVIEW.md` 逐项写 `todo|doing|done|rework`、源文件、截图和真实观察；没有图证不得标 `done`。前一阶段未过视觉检查时，先返修它，别用后续细节掩盖结构问题。

| ID | 制作动作 | 阶段通过证据 |
|---|---|---|
| S0 | 打开 t084 和 n5 无 UI 基线，按美术指导标准标注六个锚点、颜色角色与不可观察区；手工画石板接缝、左树负形与右草池轮廓设计 | `reference_analysis/` 有主参考 SHA、六锚点构图/灰度/颜色角色、三个物件的可编辑设计图及最大 3 个差距 |
| S1 | 灰模建平台厚度、前景台阶/栏杆、主石地、圆筒草池和设备组；调整新相机直到六锚点成立；马上做简易材质与灯光色块图，再锁机位 | `01_blockout.png` 和 `01b_color_key.png`；50% 缩图仍读得出近中远空间，并分清暖地面/暗设施/冷远景；方块只允许留在灰模 |
| S2 | 做可编辑试件：石板/台阶母版、圆筒池＋三种完整草簇、带主次枝的树和一组有功能连接的设备 | 石板/树/草/设施原尺寸局部图；剪影能识别物件，草为连续植被块，无明显球团、尖片或漂浮 |
| S3 | 统一材质并把四组试件放进同一镜头，未细作区域保留 S1 的色块/大体块代理以维持完整构图；使用初步最终光色输出组合试图，按四问题逐项判断 | `02_material.png`、局部图和 `METHOD_PROOF.md`；四项均 `pass` 且六锚点无缺失才常规扩批；失败就在 S2/S3 主动返修。原方法与替代方法各两轮仍失败时，按总方案止损规则进入**完整静帧的诚实交付**，状态 `quality_below_target`，不称通过 |
| S4 | 复用通过组合关的母版扩到完整可见画面，精调暖方向光、柔填充、接触影和冷色远景，输出最终全图 | `03_final.png`；近中远层次、石板统一、树冠透空、成片草和光色在原尺寸与 50% 缩图均成立 |
| S5 | 对照主参考进行独立视角的自审，先列缺点再评分；按严重度修源并重新渲染，直到静态地图门槛满足 | `REVIEW.md` 有前后图、失败反例、修改日志和真实分数；源文件可重开且贴图可找到 |

每批只改变一个主要视觉假设（允许为该假设同时调相互依赖的参数），保存修改前后同机位图、源参数、命令/退出码、耗时和 SHA；主动看非目标区域是否退步。**同一制作方法连续两次同机位试图仍无可见改善，就改母版或换方法**，不靠加面数、随机物件或改评分过关。批次经验写入现有 `planning/execution/LESSONS.md`，不要新建第二本经验库。只需要阶段图与局部图，不生成 Cocos 包、Q 全量证据或重复 ZIP。

## 静态地图验收

按 `planning/art/P1_T084_ART_DIRECTION_STANDARD_20261028.md` 的六维量表评分：构图与空间 20、物件结构 20、材质表面 20、植被 15、光色纵深 15、画风统一 10。每项先给 0–4，合计为 `Σ(权重 × 项分 ÷ 4)`，满分 100。**制作侧目标 ≥90，且各项 ≥3。** 90 指固定机位可观察视觉特征的加权达成度，不是像素相同率。主全图触发标准中的任一硬门槛即返修，即使算术总分达到 90。分数是制作自评，不能冒充独立审核批准。

验收时在 `REVIEW.md` 同时放 P1 主参考、旧基线、新静帧和各局部图，先写具体观察，再给分。执行模型在**同一次连续任务**内完成 S0–S5 和必要返修，交付最终静帧、`.blend`、真实评分及仍存差距；`rework` 只阻止错误方法扩批，不是向用户申请阶段批准。未参与制作的审图者可在完整交付后集中复核，不能成为制作完成或交付前的阻塞。用户看过成图后再决定是否另起调整轮次；旧游戏阶段的四卡门槛不适用于静帧。

## 开始与停止规则

开始时只读 `AGENTS.md`、本工作单、`planning/art/STATIC_MAP_ART_SKILLS_AND_TOOLS_20261028.md`、`planning/art/P1_T084_ART_DIRECTION_STANDARD_20261028.md` 与项目两个 skill：`.agents/skills/p1-art-director/SKILL.md`、`.agents/skills/p1-map-environment-art/SKILL.md`。旧 `P1_MAP_ART_ONLY_REVIEW_20261028.md` 仅用于追查原先诊断和代码根因；按需查 `knowledge/`。用 `python tools/maintenance/storage_report.py --depth 1` 只读查看容量；预计新增 ≥50 MiB 时按 `tools/maintenance/STORAGE_POLICY.md` 运行 `python tools/workflow.py storage --planned-growth-mib <预计值> --enforce`，遵守 15 GiB 上限。**不运行 `tools/workflow.py summary --write` 来领静态地图任务**，它显示的是暂停的游戏账本。

所有 S0–S5 结束后，向用户交付完整静帧、可重开的 `.blend`、同机位证据、真实评分和仍有的差距。四项组合关与最终 ≥90 都通过时标记 `target_met`。若原方法及替代方法各尝试两轮仍未过画质门槛，继续完成最好版本并标记 `quality_below_target`，列出未过项；**画质未达标不许冒充通过，也不许以半成品结束本次任务**。第三方 skill、插件或外部素材不可用时，优先用 Blender 原生网格/曲线/节点与本地自制贴图完成，不把可选工具当作阻塞。只有 Blender 本体或必要源文件确实无法使用、容量上限无法恢复、用户明确暂停或运行环境强制中断时，才记录阻塞与已完成的源和图。
