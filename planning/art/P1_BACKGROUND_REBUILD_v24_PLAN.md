## 一、参考图到底是怎么做出来的（拆图结论）

我把参考图裁成 4 块放大看了（`_tmp/ref_*.png`），它的构建逻辑是这样的：

### 1. 没有地平线，一条都没有
远端（v0–26）全部被**树冠 / 塔体 / 雾**吃掉。你找不到任何一条横贯画面的直边。
我们现在的 v14 那条线，来自台地在 y=15.2 **平切结束**、后面直接跳 55 m 贴图——参考图里根本不存在这种构造。

### 2. "谷"是**台地高差 + 楼梯 + 栏杆**，不是一排箱子
参考图前中景（`ref_D_valley`）：广场在高处，往下**有一段石阶**，阶边有金属栏杆，
栏杆和台阶在石板上投下斜向长影。v44–50 的暗，是**台地立面的背光面 + 梯井阴影**。
我们做成了"一排集装箱"——形状对了，语义全错。

### 3. 草是**卡片簇**，不是实体网格
`ref_B_right`：金草是成百上千张细长草叶卡片扎堆，尖端逆光发亮，整体是一个**发光的体积**。
我们用的是"挖了噪声的球/柱"，所以读作面包、干草垛。

### 4. 树叶也是卡片簇，**分层、有透光边**
`ref_A_topleft`：叶簇是一层层的 billboard 卡片，亮的边在**左上**，暗的芯在右下。
树干是深色的、被叶簇打断。整棵树把画面左上角**压死**，形成框。

### 5. 光是**左上打过来的**
- 台阶上栏杆影子朝**右下**；
- 叶簇高光在**左上**边缘；
- 左下角大暗块是树冠投影。
**我们现在的主光在右边（dir.x = −0.88，从右往左打），方向是反的。** 这一条不改，整体光影语言永远对不上。

### 6. 地面是"用过的"
石板有接缝、裂缝、污渍、磨圆的边、局部积水痕。我们的广场是一整片干净石板，
所以不管加多少设备，都像"模型摆拍"而不是"有人住的地方"。

### 7. 空气透视靠三件事，不是靠调亮度
- 远处**对比度低**（σ 小）；
- 远处**饱和度低**、偏冷；
- 远处**明度高**、边缘软。
我们现在是靠"把 v10–22 的均值抬到 127"来近似，方向对但手段单一。

### 8. 小物件定调
彩旗、锥桶、梯子、链条、管线、贴纸——这些东西不占面积，但让人相信这是个真地方。
我们场景里已经有彩旗和锥桶，但**没有把它们组织成叙事**。

## 二、为什么改了很多次还是不像（根因）

| # | 现象 | 根因 |
|---|---|---|
| 1 | 一条明显的线 | 台地平切 + 景片平贴，中间没有任何过渡物；且 M02/M03 发光强度不同（0.89 vs 1.72），接缝处直接跳 50 个灰阶 |
| 2 | 后半部分摆放奇怪 | 那排箱子是**为了压 v44–50 的均值**摆的，不是空间需要的。没有路、没有台地、没有功能分区 |
| 3 | 不像美术品 | 缺"压边剪影"（左上树冠不够黑不够大）、缺地面做旧、缺接触阴影；全画面一个暖调，没有冷暖分离 |
| 4 | 改了参数没质变 | 所有调整都在"亮度/增益"层面，几何和材质语言没变 |

## 三、"1:1 复刻"能做到什么程度

**结构 1:1：可以，而且应该做。**
层数、遮挡关系、每层的明度/饱和度/对比度、剪影位置和形状、光影方向——这些能做到和参考几乎一致。

**像素 1:1：不能作为交付。**
那等于直接用别人的美术资产（Arknights 的图），商用侵权；而且一旦换机位/换关卡就崩。
但**可以把它当"靶子"用**：切成带 alpha 的分层目标图，在场景里当构图基准，逐层替换掉——这是标准的分层 block-in 做法，不是抄。

> 一句话：**靶子用参考图，交付用我们自己的资产，中间靠"逐层替换 + 逐层比对"保证不走样。**

## 四、方法：分层对照替换（matte-lock）

```
参考图 → 切 5 层（带 alpha 的目标图 T1–T5）
      → Blender 里按同样深度摆 5 张 billboard（只是靶子，不交付）
      → 从最远一层开始，用自己的几何/材质替换
      → 每替换一层，比 3 个量：覆盖轮廓、层内明度、边缘位置
      → 达标才换下一层；全部换完删掉 billboard
```

比对指标（每层单独算，不只算全图）：

| 指标 | 怎么算 | 用途 |
|---|---|---|
| 覆盖率 | 该层 alpha 像素 / 画幅 | 形状是否够大 |
| 层内明度 | 该层像素的灰度均值 + σ | 明度语言是否一致 |
| 轮廓 IoU | 我们的层 alpha 与目标层 alpha 的交并比 | 位置/形状是否对上 |
| 饱和度 | 该层像素的 HSV-S 均值 | 冷暖/灰艳是否一致 |

全图 8 条判据继续保留，但降级为"回归测试"，不再是主要驱动力。
