> 目的：用 13 张《三角洲行动》实机截图直接取色、量比例，定出一套能落地的 2.5D 斜视风格规则。

## 0. 取色方法（可复现）

| 项 | 做法 |
|---|---|
| 样本 | 9 张实机图：核心区、离心、浮力、蓝室、黑室、总裁外部、总裁室内、试车间、撤离点 |
| 工具 | `tools/df_screenshot_palette.py`（面积加权 k-means + 分色相受光面统计） |
| 剔除 | 攻略图的荧光绿注释框（h 148–168 / s>0.62 / v>0.78），避免污染绿色统计 |
| 输出 | `reference/_df_screenshots/PALETTE.json`（每图 7 主色 + 5 强调色，含占比） |
| 读法 | **主色看面积，强调色看色相**。高饱和色只占 1–7%，但决定了"这是哪间房" |

> 注意：截图是**带光照的结果**，不是材质本色。下表给的是"受光面近似值"，
> 建模时应把它们当**目标观感**，反推 basecolor 时略降明度、略提饱和。

|---|---|---|---|---|---|
| 1 | 结构白 | `#CFD5D6` | 核心区 `#D2DADB` / 总裁外 `#C4C9C9` | 18–25% | 墙面大板、天花、设备外壳 |
| 2 | 浅灰混凝土 | `#979C9C` | 浮力 `#91959A` / 试车间 `#A3A6A2` | 10–15% | 地面、池壁、防爆墙 |
| 3 | 中灰 | `#676D6E` | 核心区 `#6A6F6E` / 试车间 `#777D79` | 10–15% | 结构件、桥架、管道 |
| 4 | 深灰钢 | `#3B4344` | 核心区 21% / 离心 18% | 15–21% | 金属幕墙、桁架、设备壳 |
| 5 | 近黑 | `#222B2D` | 离心 `#1E2A2F` / 黑室 `#21312F` | 15–25% | 阴影面、吊舱、天花内衬 |
| 6 | **HAAVK 绿** | `#3E9B63` | 黑室受光 `#73AB6A` / 阴影 `#43704D` | **3–7%** | 企业色竖板、局部整墙（黑室） |
| 7 | **青蓝饰带** | `#17707C` | 离心 `#198889` / 浮力 `#44A6A3` | **5–8%** | 墙裙、池口压边、地面收边 |
| 8 | **蓝光** | `#2F5C9C` | 蓝室 `#5D82B9`（亮）/ `#1E3862`（底） | 0–35%（蓝室独有） | LED 灯带、屏幕、标识牌底 |
| 9 | 橙 | `#C87A30` | 核心区扶手 `#916546`（受光偏低） | 0.5–2% | 扶手、压顶、警示条、门楣 |
| 10 | 警示黄 | `#D6A62B` | 栏杆 / 地面线 | 1–3% | 栏杆、地面通道线、梯梁斜纹 |
| 11 | 黄铜 | `#AA8355` | 总裁 `#AC825B`（19%） | 总裁独有 | 压条、栏杆、雕塑、饰带 |
| 12 | 深石材 | `#3A322A` | 总裁 `#2F2B21` / `#4B3B2E` | 总裁独有 | 地面、台面 |

**三条硬规则**

1. **绿不许超过 8%**：它只在竖板和黑室整墙上出现，一旦铺开就变成"另一款游戏"。
2. **橙不许超过 2%**：橙是"点到为止"的导视色，不是主题色。
3. **一栋楼只允许一个色相签名**：H1 青蓝 / H2 青 + 黄栏杆 / H3 蓝光 / H4 绿 / 总裁 黄铜。
   混色会直接毁掉"看颜色认房间"的读图效率。

## 2. 材质与构件规则（8 条）

| # | 规则 | 具体做法 |
|---|---|---|
| M1 | **直角优先** | 金属件 R≤0.05 m，混凝土件不倒角。实机几乎没有圆角，和 CW 相反 |
| M2 | **大板分缝** | 墙板 1.2×2.4 m、地面 3×3 m、分缝深 0.02 m、缝色比面深 15% |
| M3 | **三段式墙面** | 下白板（0–1.2）→ 色带（1.2–2.6）→ 上白板 + 高窗带（4.5 以上）；离心、浮力、蓝室都成立 |
| M4 | **金属三档** | 深灰钢 rough 0.45 / 中灰 rough 0.5 / 黄铜 rough 0.3 + metallic 0.8 |
| M5 | **玻璃只做两处** | 总裁玻璃盒（透光 0.8）、离心观察窗（透光 0.6）；其余房间不做落地玻璃 |
| M6 | **管道成组** | 沿墙或跨厅，一次 3–4 根，带法兰与支架，直径 0.3–0.6 m |
| M7 | **栏杆统一** | 黄色，立杆间距 1.5 m，双横杆，高 1.1 m；池边与坑边同款 |
| M8 | **做旧只在一处** | 只有试车间外墙允许水渍/污痕；其余全部干净，靠"设备型号不统一"表达旧 |

## 3. 光照

实机是**阴天偏亮的日光**，不是黄昏也不是夜景。

| 项 | 值 | 依据 |
|---|---|---|
| 天空 | `#D8DEE0` 冷白，带薄云 | 核心区、试车间图 |
| 主光 | 5500–6000K，高度角 **55–65°**（偏南） | 影长约为物高 0.7–1.0 倍 |
| 阴影 | 硬边、短影，**0.6–0.8 倍物高**（俯视可读性取 0.6） | 实机正午偏后 |
| 环境光 | 冷灰蓝 `#8FA3B0`，强度 18–22% | 阴影面偏冷 |
| 补光 | 室内 4000K 冷白灯盘，均匀；不做出光晕 | 离心、蓝室内部 |
| 暖光 | 只在总裁室（2700–3000K）与少量警示灯 | 强对比 |
| 对比度 | 高：亮部 80–90%，暗部 12–18% | 实机光比大 |
| 雾 | 无。远景靠**去饱和 + 提亮**虚化 | 试车间墙外 |

**"刚废弃"的落地方式**（保留叙事，不改亮度）：只做 3 处断电——
蓝室一段灯带（约 1/5）熄灭、黑室拱内一盏灯闪烁、试车间门洞只剩应急灯。
**不做**整体压暗、不加灰尘层、不加锈。

## 6. 与旧规范的关系

| 旧（CW 转译 v02） | 新（本文） | 原因 |
|---|---|---|
| 冷蓝灰 `#26313F` 打底 | **白 + 浅灰打底，深灰只做结构** | 实机是亮底，不是暗底 |
| 暖白 `#EDEAE3` | 结构白 `#CFD5D6` | 实机偏冷白，暖白只留给总裁 |
| 橙 5% | **橙 ≤2%** | 实机橙只见于扶手与警示 |
| 无绿 | **HAAVK 绿 3–7%** | 绿色是企业色，不能省 |
| 全倒圆角 R0.15–0.3 | **直角，R≤0.05** | 实机是硬边工业件 |
| 投影 0.5–0.6 倍 | 0.6–0.8 倍，硬边 | 实机光比更大 |
| 零植被 | **保留方形种植槽棕榈** | 实机广场成排种棕榈 |
| 30% 灯不亮 | **10–15%** | 保住实机亮度 |

## 7. 落地检查清单（灰盒出图后逐条打勾）

1. 白/浅灰是否占画面 **45% 以上**？
2. 绿色是否 **≤8%**，且只出现在竖板/黑室墙？
3. 橙色是否 **≤2%**，且只在扶手、门楣、警示条？
4. 五个房间是否**各自只有一个色相签名**？
5. 是否**没有圆角**（R≤0.05）？
6. 墙面是否有 **1.2×2.4 分缝**、地面 **3×3 分格**？
7. 阴影是否 **0.6–0.8 倍物高、硬边**？
8. 总裁室是否是**唯一暖色房间**（2700–3000K）？
9. 撤离终端是否是**墙面小盒**，而不是发光柱？
10. 是否**没有锈、没有随机污渍、没有杂草**（试车间外墙除外）？

## 8. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 白色太多，画面发灰 | 白墙容易连成一片 | 靠**分缝线 + 色带 + 阴影**三样拉结构，不靠贴图（8 px/m 下分缝已能读清，必须画准） |
| 绿色比例失控 | 绿很抢眼，一不小心铺满 | 只在竖板与黑室墙，且设 8% 上限 |
| 蓝光与青蓝带混淆 | 两者色相接近 | 蓝光只做**自发光细带**，青蓝只做**哑光面** |
| 黄铜在俯视下发黑 | 金属反射依赖环境 | 黄铜给 **metallic 0.6 / rough 0.4 + 一点自发光**，别用纯 PBR |
