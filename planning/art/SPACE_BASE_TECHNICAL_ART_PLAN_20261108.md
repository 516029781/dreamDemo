## 0. 先给结论（v1.1 已改）

**"白模感"仍是成像链路问题，不是内容不够**——这一条复核后成立，量化表完全可复现。
但 **v1.0 把最大的差异归错了因**，并且把一条假冲突写成了"唯一真阻塞"。三处方向性修正：

1. **P1 成品没有用 AgX。** 打开 `p1_autumn_courtyard/v25/scene.blend` 实测：
   `view_transform=Standard`、`look=None`、`exposure=0.34`——和 v13 同类色彩管理。
   P1 的完成度来自 **7 盏分工灯（1 Sun + 6 Area）+ 一套 14 节点的 compositor 分级栈**
   （Glare / ColorBalance / CurveRGB / EllipseMask / Blur / Noise / Mix）。
   **v13 是 `use_nodes=False`，一个 compositor 节点都没有。** 这才是最直接的结构差异。
2. **AgX 不是"对齐 P1"，但作为修 v13 自身亮端堆积的独立手段确实有效**——已做四组同机位 A/B 实测（§0.3）。
   代价是**饱和度从 0.208 掉到 0.141**，方向与 P1（0.31）相反，必须配套补饱和。
3. **Q-T3「S1 门禁冲突」是假阻塞，已降级。** 机械门禁 `space_base_check_v7.py`
   **完全不读像素**，只查文件/尺寸/SHA/覆盖/复现；S1 的数值判据在独立的
   `tools/space_base_v11_post.py`（v13 本轮**未跑**，无 S1 证据）。A/B 实测四种方案
   S1 `light_land` 全部 PASS（0.507–0.677）——AgX 把像素从 >0.80 压进 0.62–0.75，
   **反而提高了浅色占比**。

**"P1 那种效果"应迁移**：多灯分工布光、compositor 统一分级、深金属/浅地面明度分工、
真形体倒角分缝、近细中实远软。**不迁移**暖秋 HEX、无植被政策、六锚点、85 分、P1 相机。

### 0.3 色彩管理 A/B 实测（本轮新增证据）

固定条件：同 `scene.blend` / 同 `Camera` / 420×620 / Cycles 8 spp / seed 0 / 只改 `view_settings`。
对照图：`art/static_map/space_base_minigame/v13/renders/_cm_ab.png`；
原图在 `runs/20261108-1755/repro/ab_*.png`。

| 组 | 配置 | p50 | L>0.80 | L<0.30 | 裁切 | 平均饱和 | S1 `light_land` |
|---|---|---:|---:|---:|---:|---:|---:|
| **A** | Standard / None / +0.22（现状） | 0.748 | **39.0%** | 2.0% | 0.88% | 0.208 | 0.630 ✅ |
| **B** | AgX / None / +0.22 | 0.668 | 0.2% | 2.6% | 0.00% | **0.141** | 0.594 ✅ |
| **C** | AgX / `AgX - Medium High Contrast` / +0.22 | 0.701 | 0.9% | 3.8% | 0.00% | **0.155** | 0.677 ✅ |
| **D** | Standard / None / **−0.15** | 0.668 | 2.4% | 4.0% | 0.42% | 0.210 | 0.507 ✅ |

**读出来的四条**：

1. AgX 确实解决亮端堆积与高光裁切（39%→0.2%），但**不解决暗部真空**（2.0%→2.6%）。
   A3（暗部 10–15%）只能靠 L1 阴影 + L2 明度分工，不能指望色调映射。
2. **AgX 会洗掉约 30% 的饱和度**，让画面更灰。四宫格目视 B/C 明显发闷，
   **D（仅降 exposure）保留暖调且亮端收敛，观感最贴近 P1**。
3. **S1 四种配置全部 PASS**，C 甚至比现状更高 → Q-T3 不成立。
4. 低分辨率 A/B 只用于**组间趋势**；绝对值与交付 1680×2478 不同（现状 bright 39.0% vs 42.3%）。
   **P0 已完成交付尺寸复测，见 §0.4。**

### 1.3 P1 成品实测归因（本轮新增，纠正 v1.0 的核心误判）

读 `art/static_map/p1_autumn_courtyard/v25/scene.blend` 得到：

| 项 | P1 v25/v27 | v13 | 判断 |
|---|---|---|---|
| view_transform / look / exposure | `Standard` / `None` / `0.34` | `Standard` / `None` / `0.22` | **同类，不是差距来源** |
| 灯 | 1 Sun + 6 Area（warm key、2× warm bounce、yard kicker、cool sky fill、stair fill） | 1 Sun + 2 Area | **差距 ①** |
| compositor | `use_nodes=True`；Glare / ColorBalance / CurveRGB / EllipseMask / Blur / Noise / Mix / MapRange | `use_nodes=False` | **差距 ②** |
| 引擎 / 画幅 | Cycles / 1920×1078 | Cycles / 1680×2478 | 相机不可比 |

**结论**：v1.0 的 L0（AgX）不是"对齐 P1"，是"修 v13 亮端堆积"。
**真正对齐 P1 的两件事是 R1（compositor 栈）与 R2（多灯分工）**，优先级必须前置。
P1 标准文档本身也只要求"固定色彩管理做对照"，从未规定 AgX。

| **T5** | 每物件有支撑、落地阴影、边缘有厚度 | **几何倒角 + 材质层边缘暗线双管**（7 px/m 下几何倒角天生不足 1 px，见 L5）；AO 0.42→0.55 / dist 1.6→2.6 | P1 无植被政策 |

所以色温与色调映射建议在 P0 用同机位 A/B 一起定，不预设。

## 4. 分层改造 L0–L6（v1.1 重排优先级）

### L0-a compositor 分级栈（**新第一优先，真正对齐 P1**）

- `scene.use_nodes = True`，按 P1 v25 结构搭一条可开关的链：
  `RLayers → Glare(轻) → ColorBalance(冷灰基底/暖高光) → CurveRGB(S 曲线) →
  局部 EllipseMask+Blur(远景柔化) → Noise(σ 0.006) → Composite`。
- **不用暗角**（俯视正交会压掉外缘）；不用 `.cube`（Blender 4.5 无 LUT 节点）。
- 每个模块在 `render_v14_views.py` 里可独立 `--no-<module>` 关闭做 A/B。
- 预期：成片感、远景层次、冷暖分工；**这是 P1 与 v13 最硬的差距**。

### L0-b 色调映射（双候选，P0 实测选定，**不再预设 AgX**）

| 候选 | 配置 | 实测（420×620） | 判断 |
|---|---|---|---|
| **现状 A** | Standard / None / +0.22 | bright 39.0%、sat 0.208、S1 0.630 | 基准 |
| **候选 C** | AgX / `AgX - Medium High Contrast` / +0.22 | bright 0.9%、裁切 0、**sat 0.155**、S1 0.677 | 亮端最好，但**洗饱和** |
| **候选 D** | Standard / None / **−0.15** | bright 2.4%、sat 0.210、S1 0.507 | 暖调保留，**目视最贴 P1** |

- 选 C 必须**在 compositor 补饱和**（ColorBalance/CurveRGB），把 sat 拉回 ≥0.24；
  否则与 P1（0.31）方向相反。选 D 则改动最小、证据链最稳。
- `look` 正确名 **`AgX - Medium High Contrast`**（`Medium High Contrast` 实测报错）。
- `exposure` 与 `view_transform` **只在 v14 分支改**（Q-T2），v13 冻结。
- **P0 必须在 1680×2478 / 24 spp 复测**后锁定，低分辨率只定候选。

### L1 光照重搭

- Sun：`rotation (46°, 0, −70°)` → 仰角 **33°**，`angle 2.2°→5°`，`energy 4.4→3.6`（按 L0 结果重标），
  色 `#FFE7C4` 保留。
- World：两段 Z 渐变 `#DCE5E2 → #7E97A2`，`strength 0.62→0.45`。
- **补 2–3 盏分工灯**（T1）：冷天光 fill（暗部）、暖 bounce（墙内侧）、1 盏低能量 kicker（边缘）。
  能量先按现有 Shape 灯（22000 / 10000）的 1/5 起试，避免叠成一片亮。
- AO：`0.42 / 1.6 → 0.55 / 2.6`；墙内侧 1.1 m 暗带扩到 1.8 m 并做渐变。
- **阴影验算（修正 C14）**：16 m 塔在 33° 下影长 24.6 m ≈ **172 px**，44° 下 16.6 m ≈ **116 px**，
  两者都 **> 十字过道 70 px**。所以"影盖过道"**现状就存在**，不是改仰角引出的新风险；
  高杆件一律放北/东边缘（继承 v2.0 §4-L4），改仰角后需在英雄图复核是否加重。

### L2 明度重分配（不靠整体调暗，靠分工）

符号区分：`L_base` = 材质 Base Color 的 sRGB luma；`L_pixel` = 渲染后像素 luma（A1–A5 测的）。
**两者不是同一个量，中间隔着光照 + exposure + 色调映射，传递函数必须实测标定，不能按等号换算。**

| 材质族 | 现在 | 目标 sRGB | `L_base` |
|---|---|---|---:|
| 混凝土场坪 | `#B4B0A2` (0.690) | `#9FA5A3` | 0.641 |
| 沥青道路 | `#87898B` | `#6E7275` | 0.445 |
| 深灰钢 / 墙顶压顶 | `#3B4344` (0.225) | `#333B3D` | 0.225 |
| 室内地坪 | `#A0A5A2` | `#8E9594` | ≈0.57 |
| 近黑阴影面 | `#222B2D` | 保持 | ≈0.15 |

**成像目标（`L_pixel`，交付尺寸）**：p50 0.766 → **0.58–0.64**；L>0.80 → **<22%**；
L<0.30 → **10–15%**（实测 AgX 只能到 3.8%，主要靠 L1 阴影 + L2 分工）；
跨度 0.444 → **≥0.55**；sat ≥0.24（A13）。

### L3 材质族重构（63 在用 → ≤28）

- 合并同色重复：`platform` / `apron` / `garden_walk` / `causeway` → 1 个 `mat_concrete`
  + `concrete_wet` / `concrete_repaired`。
- roughness 显式拉开：混凝土 0.82–0.92、沥青 0.88（加骨料高光）、
  深灰钢 **0.42 + metallic 0.65**、玻璃 **0.08 + 透射**。
  **P0 修正**：现状不是"档数少"（实测 22 档），而是 52% 材质 ≥0.8、`metallic>0.5` 仅 1 个；
  要做的是把低粗糙度/金属面**分配到大面积可见材质**上，不是再补几个档位。
- 每材质建 `material_family` 自定义属性，供 `check_v14_art.py` 统计族数与离群。
- **同步更新 `IL_MATS` 键名**（现 9 个），否则 `apply_illustration_shader` 会静默失效。

### L4 纹理与表面响应

- `_tex_mix`：`lo 0.74~0.90 → 0.62~0.72`，`hi 1.02~1.05 → 1.08~1.14`
  （把 12–18% 的 panel 类跨度提到约 35–45%）。
- `panel` 板缝：`mortar 0.72 → 0.55`，缝宽真几何 `0.02 → 0.05 m`。
- **roughness 也接同一 mask**：现在只乘 Base Color，加 `Map Range`（0.72–0.95）驱动 Roughness，
  让修补板/走动路径有不同高光。
- 使用痕迹走材质层，不加几何（`LAYOUT_ISSUES A4` 预算教训）。

### L5 接地与边缘（**修正倒角数学**）

- 几何倒角 `w = min(0.08, mind*0.22)` → `min(0.22, mind*0.30)` 只对 **mind ≥0.73 m 的大体块**
  才取到 0.22 m（1.54 px）。占画面大头的 **0.14 m 厚地面板只得 0.042 m = 0.29 px**。
  → **不要拿 0.22 m 当全场景指标**。
- 正确做法：① 结构块按 mind 分档统计；② **地面板边缘改用材质层 1 px 暗线 + 窄磨损带**
  （7 px/m 下比几何倒角可靠）；③ 保留 `mind<0.12` 跳过门槛，不要为薄片放宽。
- A8 改为「**结构块（mind≥0.73 m）倒角 ≥1.3 px，且 ≥80% 大板有材质层边缘线**」。
- 每新增物件查接地：包围盒最低点与承托面 z 差 ≤0.02 m，写进 `check_v14_grounding.py`。

### L6 纵深与后处理（去重后）

- 水面：**已有** `#2E5A5F` shallow + `shore_fan_*` + `water_bump` + water grain。
  改为把浅滩做成**三段可辨色阶**（`#17383F → #2E5A5F → #3E6360`）并扩大礁盘透色范围，
  不是从零新建。
- 雾：取消 `is_fog` 的 `hide_render`（**这才是实际的隐藏项**），降对比 40% / 降饱和 35%，
  加线性雾 0.8–1.5%。远景岛影按分带降锐度。
- 后处理拆分见 L0-a；每项独立开关做 A/B。

## 8. 风险与不做什么

**风险**

1. 改色彩管理会改变全部既有色彩统计，v13 的 S2/S3/S15 证据全部失效 → 新 run 重跑，不能混用。
2. **改图后 MANIFEST SHA 必须重绑**，否则 `check_v7` 会报 manifest binding failure（这是最可能踩的坑）。
3. AgX 洗饱和（实测 −30%），必须配 compositor 补色；否则比现状更灰。
4. 补灯可能把亮端重新推高，与 L2 目标对冲 → 每加一盏灯都要复测 A2。
5. 长影盖过道**现状已存在**（116 px > 70 px），改仰角后需英雄图复核。
6. 材质合并会改 `IL_MATS` 键名，须同步，否则插画着色器静默失效。
7. 倒角 0.22 m 对 0.14 m 薄板只有 0.29 px；别拿它当全场景验收值。
8. 静态图无运行时 LOD/overdraw，不为套模板编 GPU 帧时间数字。

**不做**

- 不把 P1 暖秋 HEX、无植被政策、六锚点、85 分、t084 当航天基地视觉目标或门槛
- 不改画幅 240×420 / 7 px/m / 1680×2478 / 四厅尺寸 / 敞顶 / 桥 B / 试车间结构
- 不引入第三方贴图或 HDRI；不把实机截图当贴图
- 不为"完成度"补回植被或加大量装饰小件（内容见 v2.0）
- **不在 P5 前改 S1 判据**
