## 一、历史执行方式（以下不再生效）

1. **按 ID 顺序做，不跳**。每个任务的"依赖"栏写明了前置，跳过会返工。
2. 每次改动都走同一个循环：**改 → 渲（16spp/50%）→ 测（measure.py）→ 判（对验收列）**。判不过就停在这个任务里迭代，不进下一个。
3. 每个任务最多迭代 **4 轮**。4 轮不达标，说明参数假设错了，回滚到该任务的起点重读方案，而不是继续调。
4. 验收列里的数字是**分带均值 L**，口径固定 `u 0.20–0.78`，与参考同尺。

## 十一、关键路径与并行

```
P0-1 → P0-2 → P1-1 → P1-2 → P1-3 → P1-5 → P2-1 → P3-1 → P4-1 → P5-1 → P5-2 → P6-1 → P6-2 → P6-3 → P6-4 → P6-5
                            └→ P1-4 ─┘
```

- **串行主干**：P1-1→P1-2 是唯一必须等的诊断，其余都能接着做。
- **可并行**：P1-4（坡面压底）与 P1-3 互不影响；P6-2（石板）可以在 P5 之前先做，但会干扰 v60–90 的测量，建议按序。
- **不能提前**：P5-1 必须等 P4-1，因为台阶一改，v0–8 的光照和遮挡关系会变。

## 十二、停止规则

| 情况 | 处理 |
|---|---|
| 某任务迭代 4 轮仍不达标 | 停。回滚到该任务起点，回方案对应小节重读假设，不要继续调参 |
| 改动让原本达标的带跑出区间 >20 | 立即回滚这一改动，单独做一次 A/B 再决定 |
| 单次渲染超过 6 分钟 | 检查是否误开了 100% 分辨率或高采样，不应出现在中间步骤 |
| 出现破面 / 悬空 / 穿模 | 停下先修几何，不要带着缺陷往下跑（缺陷会累积到正式图） |
| 时间超预算 1.5 倍 | 收缩范围：先保住 P1+P4+P5-1（这三项决定"像不像"），P6-2 石板做旧可延后 |
