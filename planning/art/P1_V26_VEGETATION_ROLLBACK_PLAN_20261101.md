# P1 v26 植被回滚方案（2026-11-01）

## 0. 诉求与结论

用户反馈：**当前草和树叶与整体环境不搭配，想回到之前的效果。**

排查结论先行：

1. **git 里取不回旧场景**。本仓库是 code-only 提交（.blend 与渲染图均不入库），
   git 能提供的只有当时的文档与脚本。与植被相关的最相关提交是
   `7691b92`（10-28，look-dev fixes：叶色由材质槽决定避免白叶、草只留两个材质槽且调暗）——
   这些是 v24 时代积累的经验，回滚时须继续遵守。
2. **旧效果真正的可回退来源是 v25/_backup 的 4 个场景快照**，配合渲染时间线可精确定位：

| 快照 | 时间 | 状态 |
|---|---|---|
| `scene_pre_B.blend` | 07:51 | **R2 树冠重做之前**（含 R1 光修正）→ 旧树叶在这里 |
| `scene_pre_D.blend` | 07:52 | **R3 草重建之前**（含新树冠）→ 旧草在这里 |
| `scene_pre_C.blend` | 07:57 | R4 石板之前（含新树+新草） |
| `scene_pre_R7.blend` | 08:14 | R7 返修之前（树移位/草加密前） |

3. **"不搭配"的三个来源**（对照 REVIEW §12）：
   - R2：删了 4 张原叶卡（`P1 canopy inner A/B/C` + `P1 canopy top layer`），换成 3 团 clump 真叶副本；
   - R3：原 127 个草实例整体换成 3 个弯曲原型（arching/drooping/windswept ×96）+ 27 束桶栽风弯；
   - R7：树 ×1.1 移位、clump 缩放、草加密 +36 克隆、mulch 缩小——都是叠在新样式上的。

## 1. 回滚策略：选材式回滚（不整场景回退）

不采用整场景恢复（scene_pre_B 等），原因：
- 会丢掉已多轮确认的成果：光方向（影子与参考一致）、石板岁月感、设备剪影、远景雾、
  橙色悬空板真凶删除（该板在**所有快照里都存在**，09:13 才删，整场景回退必带回）；
- 快照与当前场景的对象/材质差异大，合并冲突难控。

改为：**以当前 v25 scene.blend 为基线，只从快照取回旧植被对象。**

| 层 | 保留（当前场景） | 回退（从快照取回） |
|---|---|---|
| 树叶 | — | 删 `P1 canopy clump 00-02`；从 `scene_pre_B.blend` append `P1 canopy inner A/B/C` + `P1 canopy top layer`，并恢复树的原始位置/比例（撤销 R7 的 ×1.1 与移位） |
| 草 | — | 删 3 个新原型实例（arch­ing/drooping/windswept）+ 27 束风弯 + R7 的 36 个加密克隆；从 `scene_pre_D.blend` append 原 127 草实例 |
| 光 | R1 右后上 55° | 保留 |
| 石板 | R4 岁月感 + R7 调暖 | 保留 |
| 设备/远景 | R5/R6 | 保留 |
| 橙板 | 已删真凶 | 保持删除状态 |

## 2. 执行步骤（每步留证，可中断）

- **Step 0 备份与普查**：当前 `scene.blend` → `_backup/scene_pre_V26.blend`；
  用 Blender CLI 列出当前/pre_B/pre_D 三个场景中所有 `canopy`/`grass` 前缀对象
  （名称、变换、材质），写 `V26_CENSUS.json`。名称以普查结果为准，不以记忆为准。
- **Step 1 树叶回滚**：删 clump ×3 → append 4 张旧叶卡 → 恢复树变换 →
  局部渲染树区 zoom 图（对照 `r2_tree_zoom.png` 旧构图）。
- **Step 2 草回滚**：删新草原型实例 + 27 束 + 36 克隆 → append 旧 127 实例 →
  局部渲染地面区 zoom 图。
- **Step 3 整图对比**：同机位（0.25,−20.5,8.2 / 53mm / DOF 24m）整图渲染，
  产 `final.png`（v26）与 before/after 并排对比图。
- **Step 4 用户定稿**：把对比图交给用户确认。若"旧草全量"仍差点意思，
  备选项：旧草为主体 + 少量新弯曲原型点缀（混合比例 80/20），渲染第二变体供选。

## 3. 风险与回退

- **材质名冲突**：append 时若与现有 datablock 同名会产生 `.001` 副本，
  按既有经验用 startswith 匹配核对；草/叶材质在 R3 只动过新原型，
  旧对象材质应原样保留，append 后逐一核对引用。
- **误伤**：只允许操作 `P1 canopy*`、草实例前缀两类对象；B16 灌木曾误删重建，严禁触碰。
- **总开关**：任何一步不满意，用 `scene_pre_V26.blend` 整体恢复，零损失。
- **遵守 7691b92 的 look-dev 经验**：叶色必须来自材质槽（防白叶），草只保留两个专用材质槽。

## 4. 验收标准

1. 用户主观确认：草与树叶重新与环境协调（这是最高标准，优先于任何盲评分）；
2. 光影方向不变（影子仍指向左下，与参考一致）；
3. 留证：V26_CENSUS.json、before/after 对比图、scene.blend 与 final.png 的 SHA-256
   写入 REVIEW.md §13。

## 5. 预估

约 6–8 次渲染（普查无渲染），全程可分步暂停等用户确认。
