# 静态地图美术问题、解决方案与目标（含 Skill 选型）

更新：2026-10-29。状态：**旧参考链已退出当前评审**。本文只在需要追溯工具调研时查阅；当前流程见 `STATIC_MAP_WORKFLOW_20261028.md`，目标与评分见 `ARKNIGHTS_BASE_MAP_ART_STANDARD_20261029.md`。本文的 t084 目标、旧分值和旧组合门槛均不生效。所有工具的安装和实际可用性以当前机器为准。

## 固定对照与问题—解决方案—目标

对照对象固定为 `reference/_raw_screenshots/P1/t084s.jpg` 与只读基线 `delivery/next_cycle/n5/T6/candidate_n5s1q/captures/formal_no_ui.png`。只评价环境；角色、文字、UI 和视频压缩字幕不计入色彩取样或静帧评分。P1 的原相机参数未知；新场景经六锚点构图验证后才锁新相机，之后每个“目标”都要用**新场景同一相机的前后全图与原尺寸局部图**验证，不能仅靠文字自评。

| 问题 | 解决方案（制作方法与可用 skill/工具） | 目标（画面上如何判定） |
|---|---|---|
| **1. 整体像几何拼装，缺少真实场所感。** 当前广场接近同一高度，前景台阶不显眼，孤立长椅/灯和抽象背景不能表达 P1 的平台、设施与纵深。 | S0 先按 t084 标出前景台阶/栏杆、平台、花池、设施和远景的屏幕占比；S1 锁相机做灰模，调整真实高差、平台侧壁和遮挡。借用 `reference-to-3d` 的轮廓对齐法；灰模通过后再用 `blender-hardsurface-modeling` 给台阶、栏杆、设备加可解释的连接、支撑、边缘和倒角。方块只作占位，不留在最终主物件。 | 50% 缩图仍清楚读出**前景台阶→有厚度的平台→中景设施→远景**；全图不再由单一平地、巨树冠和棕色几何背景主导。灰度剪影能识别栏杆、花池和设备的功能。 |
| **2. 树像团块或重复尖片。** 主树过大、分枝不清，树叶形状和密度缺少自然层级。 | 先确定树冠在画面中的占位和主干朝向，再做主枝、次枝、细枝；用 [Modular Tree](https://extensions.blender.org/add-ons/modular-tree/) 的非破坏节点作为可调起点，替换默认叶形并手动修剪轮廓；`blender-asset-qa` 查漂浮、穿插、法线。不要靠增加随机叶片数和三角面数掩盖轮廓错误。 | 黑白剪影可辨主干和枝向；树冠有不同大小叶团与透光空隙，边缘不是规则球/锯齿片；在最终相机 50% 与 100% 两种尺寸都成立。 |
| **3. 草丛太少且像散落纸片。** 草叶方向重复，花池出现孔洞，没有 P1 的连续金草块。 | 先手作/程序化做 3 个**根密顶疏**的草簇母版，各自有不同高度、曲率和叶宽；再用 [OpenScatter 社区分支](https://github.com/joseph-wardle/openscatter) 在花池遮罩内成组种植。局部手工修边，加入少量阔叶、枯叶和土壤露出；插件仅负责分布，不负责草簇的美术质量。 | 50% 缩图是一片有高低起伏的连续植被体块；100% 局部可见细叶、根部遮挡和方向变化，无明显尖三角、穿石板或漂浮。 |
| **4. 地板格式杂乱又缺质感。** 大片等宽矩形接缝显得机械，表面近乎单一米黄，磨损没有原因。 | 制作“标准板、边板、破损板”一套尺寸家族，统一走向和接缝宽度；边角倒角和台阶厚度用真实形体，细小磕边/污渍/粗糙度变化用可编辑材质。用 `blender-pbr-materials` 指导材质图层，从 [Poly Haven](https://polyhaven.com/license) 的 CC0 石材表面选起点并按本图色板再调。磨损集中在边缘、踩踏路径和积尘处，避免随机噪声铺满画面。 | 50% 缩图石地整体统一、没有棋盘格；100% 局部能看见真实接缝、边缘磕碰和材质起伏；台阶与平台属于同一石材家族。 |
| **5. 整体黄褐色、不好看，光照偏平。** 石地、树、草、背景的明度与色相过近，阴影偏硬，缺少 P1 暖前景与冷远景关系。 | S0 从 t084 的**环境区域**建立颜色角色：浅暖石地、金草/秋叶、深中性设施、冷青远景、柔和阴影；先灰度检查明暗层级，再用 `blender-lighting-lookdev` 设暖方向光、柔和天空填充、接触影与远景空气透视。Poly Haven HDRI 只作可调环境光起点。避免全屏黄滤镜，也不要把精确取样色值直接当 Blender 材质值。 | 灰度缩图中前景/主体/远景层级可分；彩色全图有温暖主体与偏冷远景，阴影有细节且方向一致；同机位 A/B 相比旧图色彩关系更接近 t084，而非仅饱和度更高。 |
| **6. 有局部改动却仍不像参考。** 过去容易只看脚本、面数或自评分，忽略全图构图与画风统一。 | 项目专用 `p1-map-environment-art` skill 固定参考和返修顺序；借用 `reference-to-3d` 的叠图/差异复核；`blender-asset-qa` 只检查网格技术问题。每批只改一个主要假设，保留同相机前后全图、局部图和失败反例；先写具体观察，后评分。 | 四个制作关口有真实图证；主画面与四类局部均达静态地图工作单标准。明显方块、尖片、大片单色地面或丢失外链任一未关即继续返修；不能只靠高自评分结束。 |

从单张 P1 截图只能分析**可见画面**，不能准确推定场景背面或保证 1:1 复刻完整 3D 地图。目标是拥有相同的空间、材质、植被和光色语言，同时保留我们自己的场景布局与可编辑源。

**能否解决你的问题？**制作方法现已针对固定形状、树草不像、地板杂乱、配色不好看及场景感不足设置逐项的组合试图门槛。**目前仍是未验证方案，不能保证最终画质**：第三方 skill/插件尚未在本项目试用，也没有新渲染图。先让六锚点灰模和早期色块成立，再让四组可编辑试件在**同一张组合画面**通过地板/树/草/光色四项检查；随后扩成完整静帧，按构图20、形体20、材质20、植被15、光色15、统一性10 的量表检查整图（每项 0–4，制作侧总分 ≥90、各项 ≥3，且无硬门槛失败）。只有这些图证与 `.blend` 可编辑性都成立，才能判断方案在本项目真正有效。

## 当前推荐：先证明一张画面的美术方向，再扩成场景

这次不以“装了多少 skill”作为进度。我推荐**项目美术指导 skill 定目标，Blender 原生源完成画面，外部 skill 只在对应工序提供技法**。每一关未达到可见结果就返修该关，不把问题留给最终总评。

| 顺序 | 实际动作与工具选择 | 必须留下的成果 | 继续条件 |
|---|---|---|---|
| A. 参考锁定 | 用 `p1-art-director` 打开 t084，按 `P1_T084_ART_DIRECTION_STANDARD_20261028.md` 标六个锚点和不可观察区；制作一张构图线稿、一张灰度明暗图、一张六种颜色角色表。 | `reference_analysis/` 中的标注图、主参考 SHA、六锚点表和最大三项差距；线稿可以用 Krita/SVG 手绘，不用 AI Image。 | 能指出每个锚点在最终画面的预定位置、大小关系和遮挡；不能只写“秋日、自然、真实”。 |
| B. 整画面灰模 | 在**新** Blender 工作目录建立相机并按六锚点调整；用简单体块搭平台高差、左树占位、右圆筒草池、中景设备和冷远景。立即做简易色块/灯光图，构图与色彩分工确认后才锁机位。借用 RobLe3 `reference-to-3d` 的对齐思路，不急着接入整套 MCP。 | `01_blockout.png`、`01b_color_key.png`、相机参数、P1/灰模半透明叠图与六锚点偏差记录。 | 50% 缩图能读出近中远、六锚点和暖主体/冷远景；若构图或色块错，先改相机、大体块与颜色角色，不画细纹理。 |
| C. 四件同机位试件 | 在 B 的相机和灯光下做**一段台阶/石板、一组圆筒草池、一棵树、一组工业设施**。先做硬表面结构与材质，再做树/草轮廓。只选择 EL4CTEO 中实际需要的条目；树/散布插件仅在原生方法不足时试。 | 每件物件的可编辑源、原尺寸局部图、缩图和一张含四件的整画面预览；记录用到的外部 skill 仓库 URL、commit/版本、许可证和本机试用结果。 | 台阶有厚度、石板同一材质家族且非平面；树有枝向/透空；草根密顶疏且连成块；设施可辨功能。显眼球、方盒、尖片未消除则不进入全场景扩批。 |
| D. 扩成完整静帧 | 复用 C 中通过的母版填充画面，做暖方向光、柔和阴影和蓝青远景；统一近中远资产细节密度。外部 CC0 材质只作可编辑起点，逐件调到 P1 的颜色角色。 | 同机位灰模/材质/最终三图、`.blend`、源贴图、局部图及来源清单。 | 按六维量表真实自评 ≥90，各维 ≥3，且没有硬门槛失败；原生源重开后材质与链接完整。 |
| E. 反例返修 | 美术指导先列最明显三处差距，再定本批唯一主因，修改对应网格、材质或灯光；同机位重渲染。 | 改前/改后/失败反例、参数、命令/退出码、耗时、哈希与返修决定。 | 目标区域改善且非目标区域未明显退步；同一方法连续两次无改善就换制作方法。 |

**外部 skill 的采纳顺序：**先试 EL4CTEO 的 `blender-hardsurface-modeling`、`blender-pbr-materials`、`blender-lighting-lookdev`；`blender-asset-qa` 作为技术检查。RobLe3 先仅借用“先量参考再建模、叠图纠偏”的方法，只有手工对齐无法稳定复现时才试其 MCP。`environment-artist` 用来检查场景层次和模块化，不代替项目美术指导。Modular Tree、OpenScatter 是候选工具，不在看过默认输出之前直接投入主场景。所有外部工具先在新目录试，不接入冻结 n5。

**采用或弃用规则：**每个新增 skill/插件只配一个对照任务和同机位前后图；如果不能修复对应问题、生成物不可编辑、与 Blender 5.2.3 不兼容，或结果仍像低模几何体，就不用它。安装成功、脚本退出码为 0、模型面数增加，都不算美术改善。记录结论后继续用 Blender 原生方法完成该物件，避免反复换工具耗时。

## 方法有效性审查：为什么以前的返修不能再照做

旧 n5 画面已经证明“增加物件/面数/随机数”不能稳定得到 P1 风格。`tools/blender_n5/env001_layout.py` 的铺地由规则 4×4 m 模块和随机板宽构成；默认统一样式虽可避免三种板型混铺，仍不等于按参考画好的接缝布局。`tools/blender_n5/courtyard_lib.py` 的叶簇把叶片卡随机放在簇壳上，容易保留球团与重复卡片轮廓。`tools/blender_n5/build_map001.py` 的草先生成单叶再分布，叶片数量/筛选参数不能改变草簇的设计。旧 GLB 路线还会用 `_flat_material` 简化部分材质；本静帧新路线直接验证 Blender 渲染，但不能因此忽略材质设计。上述是**现有代码的局限**，不能未经新试件证明就作为静态地图的最终主方法。

| 必须解决的视觉问题 | 首选可编辑制作方法 | 组合试渲染的通过证据 | 若仍失败，换什么方法 |
|---|---|---|---|
| 地板不统一、像线网 | 在参考图上先画石板接缝设计图，定一套主板比例/走向；只允许边板与少量破损板。Blender 中用可单独编辑的板材母版、真实凹缝/倒角、分层石材材质；台阶与平台同一家族。 | 主地面只读出一种铺装语言；模块边界不形成重复网格。50% 图看铺设节奏，100% 图看接缝深度、边缘磨损和粗糙度，而非单色平面。 | 停止随机宽度铺板，改为人工绘制的布局网格/曲线驱动板材；仅把程序用于沿已审定接缝实例化。 |
| 树冠巨大、亮黄、尖片 | 先按 t084 画树干/主次枝和树冠负形剪影，再制作不等大的叶簇母版；叶片形状、暗部与枝向手工定稿，工具只负责沿枝布置。 | 左树在画面中的占位与参考同级；50% 图可读枝向与透空，100% 图无重复折纸片；深琥珀/褐色内层与受光外层分开。 | 停止在球壳上随机加叶；换成手工枝级＋沿枝叶簇，或先选可编辑且许可清楚的树资产再重塑冠形与材质。 |
| 草少、尖、分布平 | 先制作三种**完整草簇**，让细叶从密实根部向外弯曲；在圆筒池顶部用遮罩分区成组种植，再手工修边缘和顶部轮廓。散布只控制位置。 | 50% 图的右侧草池是连续、有高低起伏的金褐体块；100% 图仍能看出弯叶、根部遮挡和少量空隙，无大片裸土或三角针。 | 停止调单叶数量/随机种子；换草簇母版的形状与高度层级，再重做分布遮罩。 |
| 全画面黄褐、硬影、无纵深 | **灰模通过后立即做全画面色块与灯光试渲染**：浅暖石地、深暖树草、暗中景设施、冷软远景分工；先锁色彩管理/曝光，再调材质与灯光。 | 灰度缩图有近/中/远明暗层级；彩色缩图能一眼分清暖主体与冷远景。地面、树、草的色值不挤在同一黄色带；阴影保留细节。 | 停止叠全屏黄滤镜或只调太阳；重新分配材料底色、填充光与远景层，重做色块样板。 |

### 扩批前的组合画面关（新增硬门槛）

1. **先定镜头，后锁镜头。** P1 原相机参数未知；以 t084 的六个屏幕锚点和遮挡关系反推新相机。灰模期间允许调整机位。完成六锚点对齐和一张简易色块/灯光图后，锁定新相机；之后同一候选的前后对照必须同相机。旧 n5 游戏机位不是静帧必须继承的机位。
2. **一张组合试渲染同时证明四项。** 在同一画面中放入通过设计的台阶/主石板、左树、右圆筒草池和中景设施；未细作区域保留 S1 的色块/大体块代理，使整幅图仍可判断光色。交付全图、50% 缩图、地板/树/草三张原尺寸局部、P1/试图并排图，以及每区的“参考→试图→差距→改法”记录。单件孤立预览只能证明资产，不能证明场景风格。
3. **四项逐一判定，不能均分掩盖。** 地板、树、草、整体光色各写 `pass|rework` 和可见证据；任一项 `rework`，不得批量铺地、种树或散布草，执行者须留在 S2/S3 主动修源重试，**在同一次连续任务中自行循环，不向用户请求阶段批准**。六锚点中的台阶、圆筒池、冷远景缺失也直接返修。组合试图全关通过后，才进入完整静帧扩批和最终 90 分六维评分。
4. **返修方法有止损点。** 同一种制作方式连续两次同机位试图仍未改善目标问题，就写明失败原因并换上表中的方法；不是暂停任务，也不是降低分数。先以低分辨率全图排查构图/色块，再渲染目标局部的最终像素密度；组合关通过才做常规高成本全图扩批。若原方法与替代方法各试两次仍未达标，改用当前最好且可编辑的结果组装一张完整静帧并交付，标记 `quality_below_target` 与具体未过项；**不在半成品阶段停工，也不把失败写成 pass**。脚本/插件可重用其技术功能，不能让旧生成形状决定最终美术。

### 额外可试的固定机位手法

本阶段只需一张静帧，因此可以采用**镜头优先的混合场景**：前景台阶、主树、圆筒池、草簇和设备保持真实可编辑 3D；远景水面、雾层和细小墙面污迹可用自绘分层贴图/可编辑投影贴花来控制画面。Blender 5.2 的 [UV Project Modifier](https://docs.blender.org/manual/en/latest/modeling/modifiers/modify/uv_project.html) 支持相机投影，适合这类固定视角贴花；官方也提示低面数透视投影可能有伪影，必须用试图检查。**只投影自制或许可证允许的图层，不把 P1 截图本身投进交付画面。**此法提高固定镜头的细节控制力，但不宣称产物自动适用于以后可行走游戏；将来转游戏时需重做不可见面和多视角材质。

### 能保证什么、不能保证什么

该流程能保证每一项关键差距在扩批前被看见、记录并触发换方法；不能从一张参考图和若干通用 skill 推导出像素级 90% 复制，也不能在没有实际新渲染时承诺最终美术品质。`≥90` 仍是项目六维可观察特征目标。**一次连续执行的交付条件**是：最终静帧和 `.blend` 可重开、同相机阶段图/局部图及真实自评交齐；若四问题组合关、六锚点、90 分也全过，标记 `target_met`。如果按上条止损规则仍未达标，也交完整可编辑静帧，标记 `quality_below_target` 并列未过项，不能冒充目标达成。期间的 `rework` 是内部返修状态，不是暂停或向用户求批。未参与制作的审图者可在交付后复核，不能成为制作或交付前的外部阻塞。用户看到成图后再决定是否要求下一轮调整。**没有完整静帧与原生源证据时，只能称“方法待验证”，不能称已交付。**

## 试点与采纳规则

1. 先完成 A 的参考分析与 B 的整画面灰模，再在**新场景内**完成 C 的四组同机位局部：台阶/栏杆/石板、圆筒草池、主树、工业设施。石板材质和草簇分别出原尺寸近图；不要把第三方插件直接接到冻结 n5。
2. 对每个候选记录“原来像什么、工具改变了什么、还差什么”，保存同相机、同光照、同尺寸的前后局部图和 `.blend`。只有真实可见改善且源文件仍可编辑，才进入完整静帧。
3. 如果某工具的默认输出是低模卡通、规则重复或颜色与 P1 不合，即使安装成功也不采用；换母版或手工调整。只保留通过试点的技能/插件，避免工具堆积。
4. 不把“有 skill”“插件运行成功”“总分自评 ≥90”当作画质事实。最终仍按 `STATIC_MAP_WORKFLOW_20261028.md` 同机位看图、逐区说明差距和返修。
