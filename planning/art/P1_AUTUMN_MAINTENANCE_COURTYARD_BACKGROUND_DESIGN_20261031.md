## 1. 最终要看见的画面

一座有使用痕迹的浅石露台位于前景。它的背后不是无限延伸的空沙坡，而是**有高差的后侧维护步道**。步道再往后，经浅色岸缘和暗色挡水立面，接一段被树冠、设备、岸线遮住两端的低饱和蓝灰水面。对岸是断续的暖土地和低植被；远树与不明确的低矮轮廓只从顶部局部露出。左侧树荫、右侧草顶圆筒共同框住中央设施和水色间隙。

观看次序应为：亮石阶/平台 → 中央设备与右侧草池 → 左树的暗形 → 中央偏后的局部冷水 → 柔和远处。水提供冷暖对照和空间深度，不能成为面积最大、对比最强的主角。远处必须像同一庭院的延续，不能像另外贴了一张独立风景图。

### 参考事实与原创补全的界线

| 参考中可直接观察 | 为让场景可制作而作的原创决定 |
|---|---|
| P1 上中部出现局部蓝青色、浅色边和暗色立面；后方偏暖；树/栏杆/设备遮住局部 | 将其解释为维护庭院后方的短段景观水道，配一个可站立的检修步道及挡水边 |
| 左侧树冠暗而不规则；右侧草筒体占据主要轮廓 | 让树下植被连到左岸；右侧先用草池与岸草收边，只有灰模仍露出无边界浅地时才补低挡墙 |
| 中央有工业设施和栏杆，右上有机械轮形 | 让管线沿设备底座去往岸边接口；机械轮有落地支架和可能的维护位置，但不强行解释原作真实用途 |
| 远处形状与具体地物被虚化、遮挡 | 只用低矮地形和树地剪影，不新增可读大楼、远山、完整池形 |

## 2. 从地面到远处的空间拓扑

设计关系固定为：`前景台阶 → 主石平台 → 后侧安全边/开口 → 维护步道 → 浅色岸缘与暗色立面 → 局部水面 → 对岸暖地 → 远树/低轮廓`。图中每条箭头表示可见的结构接续，不表示这些面必须全部同高或全部无遮挡。水面低于岸缘；后侧步道必须能从现有平台的某个开口或台阶到达。禁止让栏杆穿过通行口，也禁止把水贴在平台背面却没有岸或高差。

| 组 | 屏幕空间草图范围* | 几何与承托 | 画面作用 |
|---|---|---|---|
| 主平台后边 | 上半画面中下方，受中央设备和草池遮挡 | 现有石面及有厚度的边；栏杆在落差段连续，在入口处断开并有端头 | 说明前景平台到后方的高差 |
| 维护步道 | 中央设备背后、桥/栏杆附近，断续露出 | 石或深灰检修面；一端接入口，另一端沿岸走；宽度要能解释人的通行，具体世界尺寸按现有场景人尺度校准 | 把设备、岸边和平台连成一个用途明确的区域 |

**参数来源与使用顺序：**V16 源的相机 `(0.25,-20.5,8.2)`、欧拉角约 `(1.23617494,0,.01198983)` 弧度、焦距 `53mm`、渲染 `1920×1078`、Cycles、Standard、曝光 `-0.25`，均由只读 Blender 检查得到；当前 `50%` 预览即 `960×539`。现有后地面顶 `Z=.035`、现有水 `Z=.041`，几乎同高；这是画面像蓝色贴片的一个可检验结构原因。**B02–B13 与 B15 的新尺寸、水位和折线是起始设计值**，只有生成并比对固定镜头后才算有效。不能为了守住世界坐标而牺牲 P1 的屏幕轮廓；改值时记改前/改后、投影、理由。

**开槽实现：**复制后侧地面对象到新版本，沿 B05 多边形用可回退的切割体做 Boolean Exact；切割体贯穿旧地面厚度，应用后检查法线与洞口。若布尔留下坏面，改为手工重建水道两侧的地面网格，不能把水抬到旧地面上方伪装高差。水面 `Z=-.18` 比岸顶 `Z=.12` 低约 `.30` 世界单位；这个差值只是初始断面，局部渲染中应看得到浅沿和暗竖壁。水下已有大地面顶约 `Z=-1.27`，可作远底承托，但不得穿过水面。

**相交范围处理：**B03/B07 的矩形只是占地外包范围，实际地面网格要分别裁到 B05 开槽多边形的近岸/远岸一侧；如果建 B09，靠水端也要沿开槽边修形。B08/B10/B15 的每株草根必须在裁切后仍存在的土面或独立土带上；B09 墙体本身不能算土。不能创建完整矩形地面后再让它覆盖水面。

**旧物体退场清单：**新版本第一张试图前，隐藏 V16 的 `Curved blue green watercourse`、`Soft near water edge`、`Soft far water edge`；旧水面/旧边线不与 B04/B06/B07 叠加。`Far pale sand bank | west rolling shoulder`、`Far pale sand bank | east rolling shoulder` 要隐藏或按新对岸与远树重做；`v16 far garden | separated shallow terrain forms` 先用对象 ID 图看它是否仍形成浅米横带，若是则重排或隐藏。`Rear service terrace ground` 只在**新版本副本**开槽，V16 源不动。若旧水面还参与反射、阴影或相机可见性，也要排查，不只检查主相机图。

**开槽与步道的机械预检：**灰模前检查 B05 多边形闭合、无自交；把旧地面开槽后，在水道内选择左/中/右三个裸露采样点，从高于地面的 Z 向下射线检测，第一可见表面应是新水面或明确设计的岸，不得仍是 `Rear service terrace ground`。对 B02 先检查桥端真实可走面、三级踏步的每级顶高和 B03 接口是否连续；若桥端踏面判定不清，输出局部剖面图再定参数。用相机投影记录 B04 岸缘与 B06 水面的实际屏幕包围框，代表点坐标不能代替包围框校验。

**默认材质节点起点：**后步道沿用平台石材家族，粗糙度 `0.72–0.88`；暗岸壁 `0.78–0.92`；蓝灰水 `0.25–0.42`；涂装金属 `0.38–0.62`。这些是本项目试材值，不是从 P1 提取的原作 shader 参数。水面的颜色只按锁定参考的成图冷暖关系调，不把截图 sRGB `(125,145,154)` 直接填到 Base Color。

| 成图取样角色 | P1 截图 sRGB 中位数 | 对新背景的用途 |
|---|---|---|
| 干净浅石地 | `(216,195,170)` | B02/B03 的明亮暖色家族参考；后侧可稍暗，不另起饱和黄地板 |
| 石地阴影 | `(181,156,136)` | 岸缘与步道的遮蔽处仍需可读，不能压成黑缝 |
| 深暖叶 | `(99,61,41)` | B08/B11 的深部目标角色；受光叶仍需有变化 |
| 金草混合区 | `(174,133,91)` | B10 与现有草池保持同一金褐家族，不能变荧光黄 |
| 深金属边 | `(94,74,59)` | B14 轮/框的次要暗形，不把它做成画面最硬的黑门 |
| 冷水/远色 | `(125,145,154)` | B06 与暖石地形成冷暖分离，不是 Base Color 参数 |

取样值来自当前有效的 P1 标准，均包含光照、景深、压缩和遮挡；低级模型必须比较**最终渲染的屏幕色彩关系**，不能按表格直接设置节点 RGB 并声称达标。

**现有主角锁定：**中央设备、左主树、三组右圆筒草池及前景台阶保持现有主锚点，只因明显穿帮的承托/遮挡做局部修正。不能执行上表时顺手整体搬动主角或改相机、光照、曝光。任何起始坐标与现有可见网格碰撞时，先保留主锚点，调整背景组并重新投影。

### 推荐的遮挡顺序

在固定镜头中应看到：前平台栏杆/设备挡住部分步道，步道和岸缘挡住水的近边，左树与右草池压住水的两端，对岸暖地只从水和树之间露出，顶部远形再被近树裁掉。这样形成交错的深度，而非“平台、水、沙坡、天空”四条横向带。若某个物体的存在只能通过制造一块整齐背景色带才能被看见，应删去或重新安排。

## 3. 每组物件为什么在那里

| 可见物件 | 归属与位置 | 需要检查的连接 | 不能出现的状态 |
|---|---|---|---|
| 中央机架、罐、电箱、管线 | 主平台后缘的检修组 | 机架落地；管线经支承/弯头去往岸边或水景接口；至少保留一条能看懂的检修通道 | 电箱悬空、管道无端点、所有箱体站成一排 |
| 桥和后栏杆 | 平台到维护步道或越过局部高差 | 两端分别接可站立的面；栏杆跟随真实落差，不挡入口 | 桥在水面前自成装饰拱，桥头落在空气中 |
| 机械轮形及支架 | 后侧维护区的次要识别物 | 支架到底座或地面；轴承与轮形关系成立；尺寸低于主体草池的视觉权重 | V16 式孤立高矩形框把上缘切成硬几何 |
| 左树与树下花草 | 左侧土面/树池 | 根进入池土，低植被沿岸边成组延续，花色只作点缀 | 几棵相同小树等距站在光秃坡上 |
| 右侧筒体和秋草 | 原有圆筒设施家族 | 土面在筒内，草根聚在上沿后，叶尖可以越沿；筒后低墙/步道应解释层级 | 草从盆外或筒壁长出，多个孤立圆筒互不相干 |
| 推车、工作台与少量活动物料 | 左侧准备区 | 沿通行边停放，朝向平台可进入的一侧；旗绳固定到已有结构 | 靠增加箱、桶、锥填背景空白 |

## 4. 形状、色彩和细节密度

### 水与岸

- **轮廓：**从 P1 可见区描出水色的局部边线，按相机投影反推到场景；不可把 V16 的尖叶状蓝面直接放大或加波纹。近岸应有折转、局部被挡和厚度，远岸边界更软、更短。
- **结构：**水面、浅缘、暗立面分别建模；只有表面使用细微粗糙度/颜色变化。水不需要透明池底、强镜面天空倒影或高频波纹。先看灰模能否读出高差，再决定水材质。
- **颜色：**成图里水比石地冷、比暗叶亮，但饱和度克制。P1 的蓝青 ROI `(125,145,154)` 是截图成图样本，不是材质 RGB 参数；与参考比较应看色彩角色和面积，而不是强行把材质填成这个值。

### 树、草与地表

- 近处主树仍按 P1 标准做主枝、次枝、不等大叶团和透空；后方树群可降多边形/片层复杂度，却须共享暖暗颜色、枝叶轮廓家族。远树不要做成规则球冠或黑墙。
- 后侧植被以**不等宽的连续簇块**连接岸与树下，中心有缺口，边缘有高低变化；不是把 V16 的单棵树再复制若干次。右筒体草保持根密顶疏、金褐色起伏，草叶不得生在筒外空地。
- 对岸暖地只需少量大面、树影和方向明确的步道/坡缘，不做噪声沙纹。不能让米色地面从左到右完整贯通上半屏。

### 远处和光

- 远处最多给出“低矮树地/构筑物的局部剪影”这一阅读层级；观众不应能数清窗、砖和屋顶。边缘可以偏软，但无景深诊断图也必须看出形体与遮挡。
- 固定当前 P1 用的右上主光方向、Standard 视图变换和相机。背景只调整自己的材质、遮挡与局部阴影；不要靠改全图曝光使背景显得不空。暖亮石地、深暖叶、金草、暗金属、冷软远景各守其角色。
- 背景的光照对比和细节对比低于前景平台与主树。近岸有接触影，最远层不应在主平台投出片层形状的黑影。

## 5. 可编辑 Blender 实施方案（下一次开工时）

1. **先检查源再改。** 新建未占用版本目录，记录 V16 的源图、相机、灯光、主要对象名与 SHA；保护旧候选。对实际可见对象做一张 ID/深度诊断，确认“蓝面、裸地、远树、桥、框架”分别是谁贡献的，不凭旧对象名猜测。

4. **低分辨率同镜头色块图。** 以同宽高比的 960×539 试图，P1 与候选对照；先看缩图与灰度，再看彩色。若空间不成立，仅改地形、岸线和遮挡；不启动高分辨率渲染或批量植被生成。
5. **精化通过的大形。** 补浅岸的断面、栏杆端头、步道接缝、近岸接触影；树后簇块与远剪影使用现有可编辑资产或独立源。水面只加低频层次；如需片层，保留分层源和映射，检查 alpha 边、阴影与反射。
6. **整图回归。** 保留一张关闭景深的结构诊断及一张正式设置的全图；检查六锚点、四项组合专项、承托关系、局部材质与光色，然后按现行 85 分规则打分。背景改善不能替代石板、树草等其他低分项。
